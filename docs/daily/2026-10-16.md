   - **Chunked Prefill 干扰边界 vs P/D 分离 RDMA 带宽平衡**：建立混合部署下内联 Prefill 对同批次 Decode TPOT 的干扰公式，以及 P/D 分离（`kv_connector` 异步 `get_num_new_matched_tokens` + `allocate_slots`）的跨实例 KV 传输时间平衡点。

## 2. 两套新增原创 CPU/Offline 实验与反证

1. [`experiments/checkpoint_recovery`](../../experiments/checkpoint_recovery/README.md)（`checkpoint-recovery-offline`，`own-offline`）：
   - 在 `64` 卡（`DP=8, TP=4, PP=2`）`70B` 级合成算例中，`dedup_save_plans` 将总落盘字节从 `5,184 GiB` 降至 `980 GiB`（**`5.29x`** 写放大消除），并将负载均衡指派对比 `save_to_lowest_rank=True` 的 Rank 0 负载从 `297.00 GiB` 压至 `15.3125 GiB`（**`19.40x`** 倾斜消除）；
   - `BlockingAsyncStager` 将训练主循环阻塞从 `29.069 s` 降至 `0.659 s`（**`44.11x`** 停顿缩减），Young-Daly 最优 Checkpoint 间隔从 `52.53 min` 缩短至 `7.77 min`，有效训练吞吐比（Goodput Ratio）从 `0.8409` 提升至 `0.9964`；
   - 量化复现了当 `state_dict` 使用 Pinned CPU 张量时，`_OverlappingCpuLoader` 静默退回 `_SerialCpuLoader`，使单 Rank 加载耗时从 `7.367 s` 恶化至 `9.956 s`。
2. [`experiments/inference_slo_scheduler`](../../experiments/inference_slo_scheduler/README.md)（`inference-slo-scheduler-offline`，`own-offline`）：
   - 在 H100 级 `70B FP16 TP=4`（单步 TPOT SLO `<= 50 ms`）算例中，无分块内联 `8,192-token` Prefill 造成 **`441.91 ms`** 的 Decode TPOT 违约尖峰；Chunked Prefill（`token_budget = 2,048`，单步 Prefill chunk `2,016` tokens）将最大 TPOT 压回 **`45.01 ms`**（满足 SLO）；P/D 分离将 Decode 实例最大 TPOT 降至 **`15.11 ms`**，但需承担 `2.50 GiB` KV Cache 跨实例 RDMA 传输的 **`50.00 ms`** TTFT 附加开销；
   - 验证了 100% Prefix Cache 命中仍需回退 `1` 个 token 重算末块（`unTouch` 末块），以及 `num_preallocate_tokens = 64` 在 `32` 并发下多预留 `128` 个物理块（`0.40 GiB`）导致第 33 个请求触发 LIFO 抢占的精确容量边界。
