## 2. Phase 88（Priority 97）新增组件、实验与核心架构结论（Chinese & English Summary）

### 2.1 FlashInfer KDA 2-CTA CP 状态递推、BF16×FP4 TMEM 提前释放与分块缩放预载、分组 MXFP8 整数 UE8M0 量化、Mamba2 SSU P-Split/TMA-Ring 与 TileLang SM120 寄存器-A GEMM 展开
- **双语组件文档**：[中文](../components/flashinfer-kda-2cta-bf16-fp4-mxfp8-ssu-phase88.md) · [English](../components/flashinfer-kda-2cta-bf16-fp4-mxfp8-ssu-phase88.en.md)
- **确定性实验**：[`experiments/flashinfer_kda_2cta_bf16_fp4_mxfp8_ssu_phase88/run.py`](../../experiments/flashinfer_kda_2cta_bf16_fp4_mxfp8_ssu_phase88/run.py)
- **核心发现（ZH/EN）**：
  - `cake_warp_decode`（`#7415`, `182159eb7a`）更新 `sm_103a` 上 124 行合约（100 行切换至融合 route-pack FC1 + K512 MMA-U2 FC2，20 行切换至固定 top-10 向量 finalize，24 行切换至线性网格 K256 FC2），消除独立 route-pack 启动（每层 MoE 启动从 `3` 降至 `2`，减少 **`1.50x`**）；`cake_kda` CP 状态递推（`#7436`, `4f14b25dc6`）引入双 CTA 64 列切分记录（每 CTA `32,768 B` FP32 状态，每 SM 驻留 `2` 个 CTA），在 GB300 `CP=16` 下实现最高 **`1.0754x`**（B1 前向）与 **`1.0512x`**（B3 前向+重放+反向）加速。
  - Blackwell `mm_bf16_fp4`（`#7419`, `328e862b34`）在最后一批存储飞行中提前释放双 CTA `tcgen05` TMEM（`768x2112x2048` 达 **`1.099x`** GB300 / **`1.085x`** B200），并在小 $M$ Split-K 主循环前一次性加载转换 E4M3 块缩放（`16x1024x1024` 达 **`1.166x`** GB300 / **`1.205x`** B200）；`cake_grouped_mxfp8_quantize`（`#7431`, `bdaa2401ad`）通过 $K=4096/2048$ 行分块程序与整数位运算提取 UE8M0 缩放字节，在 `[32,1024,4096]` 16 行/组稀疏掩码下实现 **`1.3552x`**（GB300）/ **`1.3632x`**（GB200）加速。
  - `cake_selective_state_update`（`#7407`, `fdd121f46b`）新增 2/4 路 P-Split、1~2 token TMA-ring 投机解码与持久双头 z-gated 解码；`cake_all_gather_matmul`（`#6885`, `0af9594727`）追加 `producer_tail` 排空最后 `ring_depth` 级多播 `mma_done` 到达（消除 PTX §2.2.2 跨 CTA 竞态）；TileLang SM120 寄存器-A GEMM（`#3286`, `32f56122e2`）显式展开 $K$-atom 循环并将每 lane 每原子共享内存缩放加载从 `12` 次降至 `2` 次（减少 **`6.0x`**），且 `#3649`（`89b5b5b9ad`）将 `out_idx` 输出分配绑定至调用方 CUDA 流。

### 2.2 SGLang Confirmed-First 冷前缀路由与 HiCache Mooncake L3 布局暴露、vLLM RL ParamMeta 与 KV Offload 五重加固、以及 TensorRT-LLM Mamba/KDA 缓存模块化与 Beam 假设重构
- **双语组件文档**：[中文](../components/sglang-router-hicache-vllm-kv-offload-trtllm-phase88.md) · [English](../components/sglang-router-hicache-vllm-kv-offload-trtllm-phase88.en.md)
- **确定性实验**：[`experiments/sglang_router_hicache_vllm_kv_offload_trtllm_phase88/run.py`](../../experiments/sglang_router_hicache_vllm_kv_offload_trtllm_phase88/run.py)
- **核心发现（ZH/EN）**：
  - `sgl-router`（`#46505`, `eabb11a4c1`）新增 `--cache-pending-prefix-consult-below`（Confirmed-First 模式）与 `--cache-pending-prefix-max-followers` 追随上限，将 8 Worker 集群在 64 并发冷前缀突发下的最大单机排队深度从 `64` 降至 `8`（降低 **`8.0x`**）；`#40467`（`64fc5f0bdb`）新增 `/get_hicache_l3_cache_layout` 聚合各 DP Rank 的 Mooncake L3 对象键布局；`#45713`（`6a28c96a49`）在 AMD MI350X/MI355X（`gfx950`）默认启用融合 HIP KDA 解码核（将 5 阶段合并为 1 次启动，减少 **`5.0x`** 启动开销）。
  - vLLM（`#63256`, `50a184f435`）在 `ParamMeta` 上声明 RL 权重所有权与分片布局以避免 `nccl_m2n` 调用 `full_tensor()`；KV Offload 五重加固（`#61050`, `#63708`, `#62929`, `#63628`, `#63655`）向 `CachePolicy.insert()` 传入位置感知的 `req_context`（实现多批次 LRU 下 **`100%`** 运行中前缀保留）、为 P2P ZMQ DEALER 设置 `_SNDHWM=1000` 非阻塞发送、在缓存重置期间冻结二级提升、回滚失败的 NIXL 远端注册并按 `blocks_per_chunk` 隔离 OBJ 层；`#61636`（`14d593115d`）消除 3D MoE LoRA 双重锁页内存（降低 **`2.0x`**）。
  - TensorRT-LLM（`#18843`, `ba6c1fc87d`）模块化 Mamba/GDN/KDA 投机重放缓存（按实际接受 + bonus token 推进状态）并强制 `_TMA_MIN_BACKING_BYTES = 128 KiB`（`131,072 B`）支撑 Blackwell 原生稀疏 FMHA；`#20915`（`732fd63463`）在最后一级 PP 前向传播前异步重组并拷贝每束真实假设历史（`PendingBeamHistories`）。

### 2.3 FlashAttention-4 SM100 块稀疏空块零填充与 64-Head 稀疏 MLA 反向 LSE 防护、verl/Megatron/TE QAT-HDO-GTP-FP32 梯度累加、以及 Mooncake 租户高可用、NIXL GPUNetIO 独立 QP 进展与 LMCache 原生 gRPC
- **双语组件文档**：[中文](../components/fa4-sparse-mla-verl-mcore-mooncake-nixl-phase88.md) · [English](../components/fa4-sparse-mla-verl-mcore-mooncake-nixl-phase88.en.md)
- **确定性实验**：[`experiments/fa4_sparse_mla_verl_mcore_mooncake_nixl_phase88/run.py`](../../experiments/fa4_sparse_mla_verl_mcore_mooncake_nixl_phase88/run.py)
- **核心发现（ZH/EN）**：
  - FlashAttention-4（`#2906`, `86dcb5d60c`）将 SM100 `store_zero` 标为 `cutlass.Constexpr[bool]`，使块稀疏空 Q 块编译期特化走 `cute.clear(rO)` 而非读取未初始化 TMEM（`NaN` 降至 **`0`**）；`2865a891a9` 修复 SM100 稀疏 MLA 反向在 `h_q=64` 与非对齐 `seqlen_q` 下的越界 `LSE` 缩放及 Phase 4/5 共享内存竞态。
  - verl（`#8361`, `4f8f090af3` & `#8235`, `0bd668c1aa`）在 QAT 模块替换前后快照/恢复 Megatron-Bridge 并行属性，并在恢复卸载的 HDO 分布式优化器上 GPU 后调用 `opt._finish_bucket_grad_sync()`；Megatron-LM（`#7780`, `ed9c2c8c1c`）在全迭代 CUDA Graph 捕获期间为每次 GTP 通信分配独立持久缓冲区；TransformerEngine（`#3397`, `e32e1238b0`）修复 `GroupedLinear` 对 `Distributed` 封装权重的 FP32 `main_grad` 绑定（相比 BF16 累加在 `1.0` 处提升 **`65,536x`** ULP 精度）。
  - Mooncake（`#4887`, `45bbc5d16b`）新增 `X-Mooncake-Tenant-Id` 多租户命名空间隔离、`DrainSegments` 维护排空与 Standby 实时拓扑同步；NIXL GPUNetIO（`#2222`, `9e7800fc16`）为每个 CUDA 流分配独立 RDMA QP 并拆分 `xfer_prep`/`xfer_post`，使并发 64MiB 大流下的 64B 小请求 P50 延迟提速 **`5.58x`**（`452.39 -> 81.05 us`）至 **`7.36x`**（`1450.25 -> 197.09 us`）；LMCache（`#6031`, `a873f152f8`）引入原生 `grpcio`（`pygrpc`）多进程服务端模式。
