## 2. 新增原创 CPU/Offline 实验与反证

- [`experiments/cluster_orchestration`](../../experiments/cluster_orchestration/README.md)（`cluster-orchestration-offline`，`own-offline`）：
  1. **Kubelet Topology Manager 与 NVML XID 隔离矩阵**：验证双 NUMA 节点上跨 Socket GPU (`0b01`) + RDMA NIC (`0b10`) 按位与为空集被 `single-numa-node` 与 `restricted` 拒绝，而整机 8-GPU (`0b11`) 在 `restricted` 下准入、在 `single-numa-node` 下因 `Count()==2` 被拒；验证默认忽略应用级 XID `{13,31,43,45,68,109}` 与 MIG `<parentUUID,gi,ci>` 切片级隔离。
  2. **Slurm `topology/block` 层级吸附与 `_choose_best_bblock` 反碎片验证**：在 `bblock=18`、`block_levels=[0,2]`（缺失 Level 1）下，`20` 节点请求从 `raw_level=1` 向上吸附至 Level 2（锁定 `72` 节点）；`16` 节点单块请求在 `[12, 16, 18, 10]` 中精准选中 `bblock[1]`（16 节点）以保留完整 18 节点块。
  3. **256 节点（聚合 `MTBF = 1.406 h`）弹性训练 Goodput 仿真**：冷节点替换（`600 s`）+ `30 min` Checkpoint 下运行 Goodput 仅 **`65.89%`**；切换至 `4` 热备节点（`45 s` `torchelastic` 重排）+ `15 min` Checkpoint（接近 Young-Daly 最优 `551.14 s`）后运行 Goodput 提升至 **`84.58%`**，扣除 `4/260` 热备节点硬件分母后单配置节点净产出仍达 **`83.28%`**（比冷替换无热备净增 **`+9.81 pts`**）。
