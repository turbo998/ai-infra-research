## 2. 新增原创 CPU/Offline 实验与反证

- [`experiments/cluster_orchestration`](../../experiments/cluster_orchestration/README.md)（`cluster-orchestration-offline`，`own-offline`）：
  验证双 NUMA 节点上跨 Socket GPU/NIC 错位拦截与 `single-numa-node` 整机 8-GPU 拒单反例、Slurm `topology/block` 2 的幂次层级吸附与 `_choose_best_bblock` 反碎片选择，以及 256 节点同步训练在 4 热备节点 + Young-Daly 检查点下的净 Goodput 增益（`+9.81 pts`）。
- [`experiments/capacity_economics`](../../experiments/capacity_economics/README.md)（`capacity-economics-offline-sim`，`own-offline`）：
  1. **稠密 `70B` vs `671B/37B` MoE 训练与能耗账本**：证实 `671B` MoE 的单 Token 训练算力（`204.68 GFLOPs`）低于 `70B` 稠密模型（`478.12 GFLOPs`），将每百万训练 Token 成本从 `$0.9456` 降至 `$0.5355`（FP8 下进一步降至 `$0.3743` 且严格将 BF16 MFU 标为 `None`），并精确复现 Slurm 30 秒梯形积分焦耳能耗（`19,800–20,700 J/step/GPU`）。
  2. **突发流量（$\beta = 0.25$）下的 Goodput 悬崖与 P/D 分离节省**：在长上下文突发到达下，盲目按 92% 利用率定容会使期望 TTFT 飙至 `4,375.0 ms`、TTFT Goodput 暴跌至 **`7.27%`**；按 Kingman 安全水位与 P/D 分离定容（`31:5` 实例比，共 `288` 卡）比混部（`392` 卡）节省 **`104` 张 GPU（26.5%）**，而将 Prefix Cache 命中率从 `12.5%` 提升至 `87.5%`（配 FP8）可将每百万达标输出 Token 成本从 **`$12.3698` 降至 `$1.7180`（降低 86.1%）**。
  3. **四家创新公司吞吐与边缘 I/O 定量对照**：复算 Fireworks 动态批大小（`2` $\to$ `14`）与 `cached_tokens + 1` 预热、Sequoia 投机树 PCIe 卸载加速（`5.40x–6.80x`）、Groq 8/16 卡流水线延迟与 Cerebras `46 KB/PE` FIFO 缓冲列（`2–12` 列）及 `0.85 GHz` Manhattan 补偿带宽。
- [`experiments/rack_power_cooling`](../../experiments/rack_power_cooling/README.md)（`rack-power-cooling-and-fault-domain-offline-model`，`own-offline`）：
  1. **126.4 kW 液冷机柜 vs 40 kW 风冷机柜 vs PG25 高温进液退化**：验证 72x 1200W GPU 机柜（IT 负载 `118.8 kW`，墙插 `126.383 kW`）在 88% 纯水液冷（$T_{\text{in}}=32^\circ\text{C}, \Delta T=12^\circ\text{C}$）下需 `133.31 LPM` 冷却水与 `1,798.6 CFM` 风量，GPU 结温 `77.6 °C`（裕度 `+5.4 °C`）；切换 PG25 且进液升至 $45^\circ\text{C}$ ($\Delta T=10^\circ\text{C}$) 时流量升至 `165.62 LPM` 且结温达 `88.6 °C`，触发 `DCGM_CLOCKS_EVENT_REASON_HW_THERMAL`。
  2. **Slurm `power_save.c` 浪涌限流与 RAPL/XCC 能耗误差**：验证 `ResumeRate=12/min` 将唤醒 64 台 `10.2 kW` 节点的瞬时阶跃从 `652.8 kW` 压制为 `30.6 kW`（`max_tokens=3`）与 `122.4 kW/min` 斜率（耗时 `305.0 s`），复现 RAPL 32-bit 回绕与 Xeon DRAM $0.5^{16}\,\text{J}$ 单位及 XCC SD650v2 梯形积分偏差（`-62,000 J`）。
  3. **DCGM MNNVL 故障域与创新硬件机柜对比**：验证 Blackwell `RECOVERY_SUCCESSFUL` (`WARN`) vs `IMEX = DEGRADED` (`FAIL` 且 `mnnvl_rack_clique_compromised = true`)，并对比 GB200 NVL72 液冷（`126.383 kW`）、Groq LPU 风冷（`32.0 kW`, `3,795.0 CFM`, `batch=1` `13.33 J/tok`）与 Cerebras CS-3 液冷（`25.0 kW`, `35.96 LPM`, 高并发 `1.74 J/tok`）。
