## 2. 新增原创 CPU/Offline 实验与反证

- [`experiments/training_parallelism`](../../experiments/training_parallelism/README.md)（`training-parallelism-offline`，`own-offline`）：
  1. **64 卡 `70B`（`S = 8,192`）四组并行拓扑显存与步时间对比**：
     - `fsdp_only_dp64`（纯 FSDP，`DP = 64`）：稳态模型状态 `17.50 GiB`，但未切分的激活高达 `28.00 GiB`、瞬态缓冲 `3.50 GiB`（总峰值 **`49.00 GiB`**），且 FSDP AllGather/ReduceScatter 暴露在跨节点慢链路上（暴露通信 `130.91 ms`，单步总时间 **`166.96 ms`**）；
     - `hsdp_dp8_tp8_sp`（`FSDP = 8, TP = 8 + SP`）：单卡激活降至 `3.50 GiB`、总峰值显存降至 **`35.44 GiB`**，TP+SP 走机内 `400 GB/s` NVLink、FSDP 走 8 节点同列 Rail IB，暴露通信降至 `19.93 ms`，单步总时间 **`55.97 ms`**（比纯 FSDP 快 **`2.98x`**）；
     - `3d_dp4_tp8_pp2_sp`（`FSDP = 4, TP = 8 + SP, PP = 2`）：若保持 `M = 8` 微批次但 `V = 1`（标准 1F1B），流水线气泡率 `(2-1)/(8+2-1) = 11.11%` 会抵消通信缩减（步时间 `61.36 ms`）；切换为 `V = 2` Interleaved 1F1B 后气泡率减半至 `5.56%`；
     - `4d_dp4_cp2_tp8_sp`（`dp_shard = 4, CP = 2, TP = 8 + SP`，联合 `fsdp = 8`）：将单卡序列长度再切半，激活降至 **`1.75 GiB`**（比纯 FSDP 缩减 **`16.0x`**），总峰值显存降至 **`33.69 GiB`**，步时间 **`56.37 ms`**。
  2. **FSDP2 `Shard(dim = 0)` vs `Shard(dim != 0)` 瞬态峰值反例**：当 TP 已占用第 0 维导致 FSDP 被迫使用 `Shard(dim = 1)` 时，`foreach_all_gather_copy_out` 额外分配的拆分缓冲使单层瞬态缓冲从 **`3.50 GiB`** 膨胀至 **`5.25 GiB`**（**`+50.0%`**，净增 `1.75 GiB`）。
  3. **CP = 8 因果 Ring Attention 负载倾斜与首尾配对**：顺序切分下 `Rank 7` 算力为均值的 **`1.875x`**（与 `Rank 0` 差距 **`15:1`**，拖慢步时间 `+87.5%`）；开启 `_RoundRobinLoadBalancer` 首尾配对后全部 8 个 Rank 严格均衡为 **`1.000x`**。
  4. **MoE DeepEP v2 训练态 Compact 去重 vs 推理态静态展开**：在 `E = 64, EP = 8, top_k = 8, tokens = 4,096, H = 8,192`（BF16）下，推理态静态展开单卡发送 **`512.00 MiB`**，而训练态 Compact 唯一目标 Rank 去重将跨节点发送量降至 **`319.99 MiB`**（无放回精确值，节省 **`37.50%`** 跨节点 RDMA 流量；独立均匀近似为 `344.08 MiB`）。
