## Phase 43 (`priority: 52`) 三大核心课题与量化结论

### 1. FlashInfer Cake GDP Nemotron 4 解码/MTP、NVFP4 `4/6` 槽位追加与 Cake Conv1d 反向路由
- **中英深挖文档**：
  - 中文：[`docs/components/flashinfer-cake-gdp-nemotron4-nvfp4-4over6-slot-append-causal-conv1d-bwd.md`](../components/flashinfer-cake-gdp-nemotron4-nvfp4-4over6-slot-append-causal-conv1d-bwd.md)
  - English：[`docs/components/flashinfer-cake-gdp-nemotron4-nvfp4-4over6-slot-append-causal-conv1d-bwd.en.md`](../components/flashinfer-cake-gdp-nemotron4-nvfp4-4over6-slot-append-causal-conv1d-bwd.en.md)
- **确定性复现实验**：`experiments/flashinfer_cake_gdp_nvfp4_4over6_conv1d_bwd/run.py --check`
- **关键量化结论**：
  1. `flashinfer.cake_gdp.cake_gated_delta_product_mtp`（PR `#6883`, `fc1790f4ec`）面向 Nemotron 4（$K=128, V=64, n \in \{1..4\}$ 阶 Householder 更新，FP32 状态池）提供 `splitv8_tile8`（$T=1 \land B \times H_V \le 160$，8 CTA/头）与 `lanerow`（$T \ge 4$ 或 $B \times H_V > 160$，1 CTA/头寄存器驻留）双核体路由，在 **GB200 (`sm_100a`) 48/48 形状全胜（`1.01x–3.99x`，`HV=10, B=256, T=8` 从 `301.4 us` 降至 `75.5 us`）**，在 **GB300 (`sm_103a`) 47/48 形状胜出（`0.98x–3.95x`，峰值 `296.6 -> 75.1 us`）**。
  2. `nvfp4_quantize_append_paged_kv_cache_with_slot_mapping`（PR `#6013`, `52fbbd090c`）新增 `nvfp4_4over6` 块缩放选择（对比 $sf_6 = \text{amax}/(6g)$ 与 $sf_4 = 1.5 \cdot sf_6$ 的 16 元素重构 MSE，次峰值聚集块 MSE 降低 **`99.65%`**），并通过独立 JIT 模块 `page_nvfp4_4over6` 保持默认 `page` 模块 **51 个内核 SASS 零变化**；PR `#6204` (`3821440929`) 移除 CUDA `k_scale`/`v_scale` 上的 `.cpu()` 流同步，使 SM80 vLLM `Qwen3.6-35B-A3B-NVFP4` 20 层 Eager 预填充延迟从 **`499.4 ms` 降至 `451.7 ms`（节省 `47.7 ms` / `-9.55%`）**。
  3. `cake_causal_conv1d_train`（PR `#6930`, `7c866e85d3`）更新 `sm_103a`（$512 \le C < 768$ 启用 `fold_overlap + fast_roll`，GB300 8 组 `C=512` 几何平均加速 **`1.0164x`**）与 `sm_107a`（$512 \le C < 1024$ 启用 `fold_overlap + fast_roll`，$C \ge 2048$ 启用 `fast_roll + roll_prefetch`，Rubin R200 11 组路由形状几何平均加速 **`1.0331x`**，峰值 `101.3 -> 96.4 us` **`1.0513x`**）。

### 2. TensorRT-LLM CuTe DSL 非整除 `next_n` DSA MQA Logits 切分、KV 传输 `Backend` 契约与 vLLM `ThreadedWatchDog`
- **中英深挖文档**：
  - 中文：[`docs/components/trtllm-dkg-cute-dsa-mqa-logits-kv-transfer-contract-vllm-shm-watchdog.md`](../components/trtllm-dkg-cute-dsa-mqa-logits-kv-transfer-contract-vllm-shm-watchdog.md)
  - English：[`docs/components/trtllm-dkg-cute-dsa-mqa-logits-kv-transfer-contract-vllm-shm-watchdog.en.md`](../components/trtllm-dkg-cute-dsa-mqa-logits-kv-transfer-contract-vllm-shm-watchdog.en.md)
- **确定性复现实验**：`experiments/trtllm_dkg_dsa_mqa_kv_contract_vllm_watchdog/run.py --check`
- **关键量化结论**：
  1. TRT-LLM PR `#19976` (`033f2ea020`) 在 `sm_100f` 默认启用 `use_cute_dsl_paged_mqa_logits=True`，并通过 `_pick_dsl_split` 与 `_atom_ctx_offsets` 对质数/非整除 `next_n`（如 `5` 或 `7`）在 `waves_atom1 >= 16` 时执行内核级切分（$\text{num\_atoms} = \lceil \text{next\_n}/3 \rceil$），将 `next_n=5`（因果偏移 `[2, 0]`）和 `next_n=7`（因果偏移 `[4, 2, 0]`）的每步分页 KV 读取次数分别减少 **`60.00%`**（$5 \to 2$）与 **`57.14%`**（$7 \to 3$），在 GB300 上取得 **`1.04x–2.60x`** 实测加速。
  2. TRT-LLM PR `#20117` (`a9000fe10e`) 形式化定义分离式 KV 传输 `Backend` / `SlotRegion` / `View` / `Outcome` / `Attempt.quiesced()` 契约，强制规定未交付（Undelivered）槽位内存仅在 `Attempt.quiesced() == True` 后方可安全复用；PR `#20608` (`16d26df5a7`) 在 `RemoteMpiCommSessionServer` 停机等待期间以 `0.1s` 周期轮询控制套接字并引入 `SHUTDOWN_ACK` 重连确认机制。
  3. vLLM PR `#55700` (`1c87991978`) 引入进程级 `ThreadedWatchDog`（`timeout=300s, check_interval=10s`），通过 `with get_watch_dog().disable():` 挂起 `shm_broadcast` 空闲等待窗口（590s 空闲等待 `0` 误报），并对每次真实 RPC 卡死严格执行单次全线程栈转储（One-Shot Dump per Stall）。
