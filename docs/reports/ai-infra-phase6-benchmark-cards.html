7 / 7 · MY TAKE GOOD FIT VS NOT FOR & READINESS

Architect's Decision Guide: When to Deploy Switch SHARP, Asymmetric Het-PP & Cross-Gen KV Transcoding

✅ Good Fit

  • Large-Scale DP / FSDP / Context-Parallel Collectives (≥64 GPUs): Grant scarce switch SHARP groups via scheduler admission control to multi-node gradient/activation reductions where 1.0× inter-node volume yields 3.44×–27.91× speedup over Ring.
  • Brownfield Hopper + Greenfield Blackwell Fleet Expansion: Partition heterogeneous GPUs across Pipeline Parallelism stages using Megatron's --pipeline-model-parallel-layout (`1:3` layer ratio + decoupled MTP/Loss tail stages) to eliminate the 43.87% straggler tax.
  • Cross-Generation P/D Disaggregated Serving: Run compute-heavy Prefill on Blackwell B200 NVFP4 and memory-bound Decode on Hopper H100/H200 FP8, transmitting compact 288 B/tok/layer payloads over RDMA with receiver-side fused transcoding.
  • Full-Stack Hopper Retrofit before Hardware Refresh: Upgrading software/fabric (`FP8 1x128 + UEC spray + NVRx + 3FS + ORv3 CBU + P/D disagg`) on existing Hopper clusters cuts token cost by 79.5% ($18.10 → $3.72 / 1M) and saves 33.63 MW facility power.

⛔ Not For

  • Unregulated Multi-Tenant CollNet Allocation: Allowing every small job or auxiliary sub-communicator to claim switch SHARP trees exhausts the 64 group limit and triggers a 3.89×–4.56× P99 Ring-fallback congestion storm.
  • Bit-wise Deterministic Auditing on Dynamic BF16 Switch Trees: Never rely on dynamic-arrival BF16 switch reduction for cryptographic gradient hashing or RL replay verification (100.0% bit-wise drift); enforce FP32 switch accumulation + static slot order or NVLS_TREE.
  • Mixing H100 and B200 Inside the Same TP or MoE EP Group: Tensor Parallelism and DeepEP All-to-All synchronize at every layer; hardware heterogeneity inside a TP/EP group forces B200 to run at H100 speed with no layout workaround.
  • Upcasting KV Cache to BF16 Before RDMA Transfer: Inflating SM100 KV cache to 1,152 B/tok/layer before network transmission wastes 4.0× NIC bandwidth and adds 151.69 ms TTFT stall at 128K context.
