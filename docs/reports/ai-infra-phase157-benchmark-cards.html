Architectural Guidance for Solutions Architects

✅ Good fit

  • Blackwell (`sm_100a`/`sm_103a`) and Vera Rubin (`sm_107a`) deployments using tail-N-split GEMM, preemption-safe MegaMoE v3, and single-copy MXFP8 expert refit writeback.
  • RL post-training pipelines using `VLLM_RELOAD_MODE=direct` in-place weight reloads and Mooncake `fmix64` lock-shard hashing + chunk reference counting.
  • ROCm MI300X/MI355X workloads with mixed-dtype elementwise tails and MiniMax-H3 bit-exact fused RMSNorm/RoPE.

⛔ Not for

  • Hashing slab-allocated C++ pointers (`sizeof(T)` sharing factors with $2^k$) via raw modulo without a bit-avalanching finalizer (`fmix64`).
  • Launching fixed `k_slices` reduction kernels on small vocabularies without clamping `k_slices <= ceil(V / TILE_V)`.
  • Registering unbacked virtual page-envelope reservations into host DMA pools or deserializing Libfabric RDMA metadata without checking `importStr()`.
