Bias correction uses the parameter step, not the row's first appearance

  coalesce duplicates, keep stored zero keys
  t = current per-parameter step
  m = beta1*m + (1-beta1)*g
  v = beta2*v + (1-beta2)*g*g

scale = lr*sqrt(1-beta2^t)/(1-beta1^t)
delta = scale*m/(sqrt(v)+eps)
