May match is not a match.
可能命中，不等于已经命中。

WHERE NOT(x>9) 的四组样本只读取组 0/3，保留全部 6 条匹配行；错误地对 may-match 位取 NOT，会漏掉组 3 的 3 条匹配行。

min=max=7 不证明没有 NULL；missing statistics 应扩大可能性，不是当作零值或无数据。

边界：均匀压缩 column chunk 字节与 selected groups 均为用户输入假设，不是引擎预测/实际 IO。零候选组也保留元数据预算。

原始整数 SQL 三值模型不实现 Parquet、DuckDB、浮点 NaN、collation、嵌套列、page index 或 Bloom filter。通过 metadata gate 的组仍需逐行过滤；不把 CPU 原型时间冒充 object-store 吞吐。
