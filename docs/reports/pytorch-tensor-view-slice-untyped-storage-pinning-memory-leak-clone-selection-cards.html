Detaching `UntypedStorage` & Pre-`lm_head` Token Gather

// ⛔ BAD: Projects all 8,192 tokens & pins 1 GB storage per slice! logits = lm_head(hidden_states)[:, -1, :] # Allocates 9.96 GB! cache.append(hidden_states[:, -1, :]) # Pins 1.00 GB for 128 KB!
↓ Pre-`lm_head` Gather + `.clone()` Storage Detachment (<answer>)
// 🏆 GOOD: Clone slice FIRST (128 KB storage), then project only 1 token! last_hidden = hidden_states[:, -1, :].clone() # Frees 1.00 GB parent HBM! logits = lm_head(last_hidden) # 0.08 ms, 1.2 MB! cache.append(last_hidden) # Holds only 128 KB!
Audit rule: `assert t.untyped_storage().nbytes() <= 2 * t.nbytes()`.
