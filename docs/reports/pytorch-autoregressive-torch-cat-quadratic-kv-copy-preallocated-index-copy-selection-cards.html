7 / 7 · MY TAKE

Architect Verdict: Never Call torch.cat Inside an Autoregressive Decode or Rollout Loop

✅ Good fit
• HuggingFace `StaticCache` (`cache_implementation="static"`) with `torch.compile`
• Custom autoregressive token/KV/hidden-state collection loops (`index_copy_` with GPU tensor `cache_position`)
• Paged KV slot-mapping writes (`reshape_and_cache`)
⛔ Not for
• Calling `torch.cat([past, new], dim=...)` at every decode step (`DynamicCache`)
• Using Python integer slicing `buf[:, step]` inside CUDA Graph captured regions
