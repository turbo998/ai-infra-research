ROUND 105 · ORIGINAL SCALAR GRID · SYNTHETIC ALLOCATION

Hash collisions share gradients.
碰撞共享参数，LoD 不回收参数。

四个插值角点可落到两个共享桶。反向必须累加每次出现的贡献；soft LoD 的上游梯度需要同一个权重。lod=0 的首层仍受 +1e-3 约定影响。

边界：仅支持二维/三维、整数倍率 1/2、每层分辨率 ≤65536。输出是 exact integer logical payload，不认证 native feature specialization 或浮点边界。

Ideal dense vertices 不是上游支持的 dense allocation；hash tables 全部分配，降低 LoD 不减少该数字。未计 gradients、optimizer、staging、峰值 HBM。
