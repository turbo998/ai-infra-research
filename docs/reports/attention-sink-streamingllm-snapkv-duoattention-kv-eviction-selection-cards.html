底层内幕：Attention Sink 的 Softmax 分母公式与 DuoAttention 显存账本

# 1. 为什么第 0~3 个 Token 会成为 Attention Sink？(Softmax 归一化分母效应) # Softmax(x_i) = exp(x_i) / (exp(x_0_sink) + sum_{j=1..t} exp(x_j)) # 因为因果掩码下 Token 0 被后续所有位置看见，模型训练出极高的 exp(x_0_sink) 作为“分母调节阀”； # 一旦滑动窗口丢弃 Token 0，分母骤减导致噪声项权重暴涨，输出瞬间变为乱码 (PPL=1,420)!
