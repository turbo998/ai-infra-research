4 / 7 · UNDER THE HOOD

Composite Tenant-Salted Block Hash & S3-FIFO Admission

// 1. Cryptographic chained block hash (prevents leak & collision) def compute_block_hash(parent_hash: bytes, tokens: tuple[int, ...], tenant_salt: str, lora_id: int, mm_uuid: str) -> bytes: h = hashlib.sha256(parent_hash) h.update(f"{tenant_salt}:{lora_id}:{mm_uuid}:".encode()) h.update(struct.pack(f"<{len(tokens)}I", *tokens)) return h.digest()
↓ Scan-Resistant S3-FIFO Eviction (<answer>)
// 2. One-hit 128K RAG blocks stay in 10% Small-FIFO and never // evict multi-hit conversational prefixes in 90% Main-Tree! if block.access_count >= 2: promote_to_main_radix_tree(block)
