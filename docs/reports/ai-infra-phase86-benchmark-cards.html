// [4] NIXL GPUNetIO Two-SGE WRITE Pairing Predicate (nixl PR #2172)
inline bool canPairWrite(uintptr_t addr, size_t len, uint32_t key,
                         uintptr_t next_addr, size_t next_len, uint32_t next_key,
                         size_t remaining, size_t max_len) {
  return remaining > 2 && len != 0 && next_len != 0 && key == next_key &&
         next_addr >= addr && next_addr - addr == len && len <= max_len - next_len;
} // 4096 x 4 KiB descriptors -> 2047 pairs + 1 odd + 1 final arrival-marker WQE = 2049 WQEs

Architectural Guidance: Where to Deploy Phase 86 Optimizations Immediately vs Where to Gate

✅ Good fit (Deploy Now)

  • Long-Vocab / Long-Context Softmax on B200/GB300: Per-tile turnover ring (`4 < tiles <= 16`) yields up to `1.247x` speedup without extra SMEM.
  • FlashKDA N16 & FA4 SM100 MLA Training: Mandatory 10-slot single-owner ring (`0` hangs), `ptxas -O2` (`0 B` spill), and 3-stage TMEM `dV` pipeline at 64 heads.
  • Large-Batch Diffusion & Multimodal Serving: TRT-LLM QuACK BF16 SwiGLU epilogue (`448 MiB` saved at $M=8192$) and SGLang zero-sync diffusion caches (`50x` fewer uploads).
  • Truncated-Sampling RL & Tiered KV Fabrics: veRL `score_centering_top_p: true` when `top_p < 1`, Mooncake 2MB THP EFA budgeting (`>88 GiB` stores), and NIXL 2-SGE WRITE pairing.

⛔ Not for (Guard / Fallback)

  • Sub-Wave Unsplit Decode on FA4 1CTA MLA: When $2 \times \text{tokens} \times H_{kv} \le 152$ (`<80` tokens on GB300) with `num_splits=1`, 2CTA is `14–31%` faster than 1CTA.
  • Small-M Decode with QuACK Fused SwiGLU: At small token counts ($M \le 32$), unfused cuBLAS + SwiGLU remains slightly faster; keep `fuse_bf16_gate_up_swiglu` opt-in.
  • Pooled Intel XPU USM Allocations for Direct RDMA: Unless `EnableDeviceUsmAllocationPool=0` is set, Mooncake `hasDedicatedDmabuf` rightly rejects pooled buffers (`kExportPooled`) to prevent cross-allocation exposure.
  • Attached Streams on NIXL Peer-Owned VRAM: GPUNetIO PeerDirect `ibv_reg_mr` requires producer completion before posting and rejects attached app streams.
