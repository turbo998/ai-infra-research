ROUND 113 · SIGNED FLOOR · COUNTS ARE NOT TAIL VALUES

Preserve boundaries, not only counts.
计数对了，还要检查桶边界。

十条 exact observations 的 span 从 8 缩至 3，scale 从 0 降到 -2。Floor 映射保留全部边界；错误 signed truncation 虽保留 10 counts，却有 3 条 interval violations。

Positive bucket 的负 index 表示较小正数，不是 negative observation；两种“负”不可混用。

边界：选定 fresh circular counters 按 2 的幂向上取 capacity，每状态另加一个 uint64 zero counter。历史 clear/downscale 后可能保留更大容量，不能据此推总内存。

Live states/stream 是用户预算假设，不声称 hot/cold 两份永远都满。原创模型只含非负整数/Fraction、scale -10..0、zero threshold=0，不实现 native SDK concurrency、negative observations、positive-scale float mapping 或 DELTA/CUMULATIVE reset。
