Perturbation & Consistency Analysis

1. 为什么 TCP WebSocket 在 3%~5% 丢包下彻底不可用？ 因为 TCP 无法跳过丢失的旧语音帧，内核强制阻塞后续所有已到达的语音包等待重传（RTO 指数退避），造成长达 2~3 秒的静音后突然快放。

2. 跨机房会话中途故障转移（Mid-Call Failover）：由于 Tier 4 每步同步产出轻量级内心独白文本流，当某个 GPU 节点故障时，网关只需将几 KB 的文本上下文 + 1.5s 尾部音频重注入备用节点即可在 `200ms` 内无感续接通话！

Robustness Conclusion: `UDP WebRTC + Opus FEC` is mandatory for last-mile voice transport; never expose raw TCP WebSockets to mobile clients.
