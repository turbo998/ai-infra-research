UNDER THE HOOD

DDP averaging turns the source clamp into max(global objects, world size).

Synthetic costs · independently_reproduced=false · Original CPU timings separately measured; no detector AP/FPS.

# Matching branch: no differentiation through discrete indices
cost = weighted(class_cost, L1_cost, -GIoU)
indices = one_to_one_assignment(cost.cpu())
coordinate_loss = matched_pair_loss(indices)

# Actual source also classifies unmatched queries as no-object.

↓ count scaling compensates for gradient averaging

N = all_reduce_sum(local_object_count)
D = max(N / world_size, 1)
local_coordinate_loss = local_sum / D
ddp_gradient = sum(local_gradient_sum) / (world_size * D)
             = total_gradient_sum / max(N, world_size)
Clamp is intentional source behavior. For N ≥ world size this equals the object mean; below that boundary it does not. Generic global-mean advice must not erase the clamp.
