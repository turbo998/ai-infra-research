4 / 7 · UNDER THE HOOD

Exact `16Ψ` ZeRO-1/2/3 & 3D Sharding Equations

# 1. Mixed-Precision AdamW Static Memory per GPU (N DP Ranks)
M_DDP = 2*P + 2*P + 12*P = 16*P
M_ZeRO1 = 2*P + 2*P + (12*P / N) # Shards Optimizer only
M_ZeRO2 = 2*P + (14*P / N) # Shards Opt + Grads
M_ZeRO3 = 16*P / N # Shards Weights + Grads + Opt

# 2. 3D Parallel Static Memory (TP * PP * ZeRO-1 DP)
M_3D = (4*P)/(TP*PP) + (12*P)/(TP*PP*DP)
With `TP=8, PP=2, DP=8` on `70B`, static state drops from `1,120 GB` to `24.1 GB/GPU`!
