static CUTLASS_DEVICE void wait_init(uint64_t* gmem_split_barriers, const uint32_t& m_block_idx) {
    const auto current_barrier_base = encode_state(Epoch::get(gmem_split_barriers));
    const auto split_barrier_ptr = get_ptr(gmem_split_barriers, m_block_idx);
    // Unsigned wrap-around rejects stale epochs (< base) while accepting 0..kNumSplits-1 arrivals
    while (ptx::ld_acq_gpu(split_barrier_ptr) - current_barrier_base >= kNumSplits) {}
}
static CUTLASS_DEVICE void retire(uint64_t* gmem_split_barriers, const uint32_t& num_ctas) {
    const auto exit_count_ptr = get_exit_count_ptr(gmem_split_barriers);
    if (ptx::atomic_add_rel(exit_count_ptr, 1) == num_ctas - 1) {
        __threadfence(); *exit_count_ptr = 0;
        const auto epoch_ptr = get_epoch_ptr(gmem_split_barriers);
        ptx::st_rel(epoch_ptr, *epoch_ptr + 1);
    }
}

7 / 7 · MY TAKE · GOOD FIT VS NOT FOR & READINESS ARCHITECT DECISION GUIDE

Production Adoption Guide for Bucketed Symmetric Memory, Epoch Barriers, Deferred KV Offload & Async Staging

✅ Good Fit (适用场景 / 推荐采纳)

  • Dynamic-Shape TP Symmetric All-Reduce + CUDA Graphs: Use quarter-power-of-two capacity bucketing (step = 1 << max(0, bit_length - 3)) while keeping historical buckets alive so graph replays never dereference freed symmetric pointers.
  • Persistent Multi-Split Kernels in CUDA Graphs: Embed an explicit 64-bit Epoch and 32-bit exit_count in the unused tail of the first 128B barrier line rather than relying on PTX %gridid.
  • Tiered KV Store Bucketed SSD Offload: Pair backend tail deferral with caller-side PartitionUnbucketedTasks and RemoveUngroupedOffloadingObject on re-PUT collisions.
  • VLM / RL Inference Payload Offloading: Copy prompt_tokens and media_tensors to CPU synchronously on completion, run stager.stage() in asyncio.to_thread, and send ZMQ replies exclusively on the event-loop thread.

⛔ Not For (不适用场景 / 架构禁忌)

  • Single-Buffer Realloc on Graph-Captured Streams: Never free and reallocate a single scratch buffer when a larger dynamic shape arrives if earlier shapes were captured into active CUDA Graphs.
  • SM120/SM121 In-Kernel RHT Swizzle Assumption: Do not mark SM120/SM121 RHT NVFP4 outputs as with_gemm_swizzled_scales=True in Dynamo fake propagation; SM12x uses compact 1D TMA scales plus post-quantize swizzle.
  • Adding alignment - 1 to 0-Based Power-of-Two Allocators: Never add leading alignment slack to requests already aligned to 2^a; it crosses size-class boundaries and wastes 12.5%+ capacity.
  • Mutating HybridDeviceOptimizer Sub-Optimizer Devices: Never loop over hdo.sub_optimizers to force .to("cpu") in external RL offload hooks.
