ROUND 109 · SHAPE CONTRACTS · SYNTHETIC SIGNATURE POLICY

One export is not one executable.
一次导出，不等于一个编译产物。

Symbolic tracing/lowering 与 concrete compilation 不同层。本计算器固定 dtype/width/target/layout，只统计 batch 签名，不观察 native JAX compile events。

整数契约：3*b+1=25、b+c=13、2*c=10 解为 b=8,c=5。除法有余数、非正维度和重复维度矛盾都应报错；未知比较不是 false。

Bucket padding 必须配套正确的有效位置语义，不能假设对 reduction/attention 无影响。所有字节为 logical input payload，不含 executable cache、allocator 或 peak HBM。
