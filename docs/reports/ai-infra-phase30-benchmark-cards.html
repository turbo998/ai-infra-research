Why Little-Endian `int32` Bit-Shift Works in `_RotateTail` (`2fddc6b7a0`):
In little-endian memory, `pairs = x.view(torch.int32)` places element `x[2i]` in bits `[0..15]` and `x[2i+1]` in bits `[16..31]`. Because a `bfloat16` is literally the upper 16 bits of an IEEE-754 `float32`, `(pairs << 16).view(torch.float32)` and `(pairs & ~0xFFFF).view(torch.float32)` reconstruct exact `fp32` values in registers while keeping global/shared memory loads and stores as contiguous 32-bit words.

7 / 7 · MY TAKE · GOOD FIT VS NOT FOR & READINESS ARCHITECTURAL GUIDANCE

Production Readiness: When to Deploy In-Row `int32` MLA RoPE, Remote Sentinel EP Masks & CXL DAX Offset Pools

架构师选型指南：明确三组核心技术在生产集群中的最佳适用场景（Good Fit）与架构禁忌（Not For）。

✅ Good Fit / 推荐采用场景
  • Rubin / Blackwell TMA Epilogue Reuse (`#6307`): Always pair `cp_async_bulk_commit_group()` + `cp_async_bulk_wait_group(0, read=True)` before `epilog_sync_barrier` whenever `sC` is reused across tiles.
  • MoE EP Split Dispatch (`#6840`): Pass global `num_experts` into `build_activation_pack_rank_major` so `-1` non-local picks map to `(offset + local) % num_experts` and skip GEMMs even under CUDA Graph replay.
  • Persistent SM100 TMEM Kernels (`#6740`): Always issue `tcgen05.wait::ld.sync.aligned;` before the CTA barrier preceding `tcgen05.dealloc`.
  • DeepSeek-V3 MLA & Multi-Graph FlexAttention (`#5529/#5442`): Use `@local_compile("mla_qk")` with `_RotateTail` `int32` views (`max_pointwise_cat_inputs: 0`) and set `recompile_limit=16, fullgraph=True`.
  • Multi-Server CXL L1 Sharing (`#5874`): Partition `/dev/dax0.0` via disjoint `2 MiB`-aligned `--l1-devdax-offset-gb` ranges backed by `sysfs` `major:minor` capacity/alignment checks.
⛔ Not For / 严禁误用边界
  • Single-Region RDMA L2 Adapters on Multi-Arena DAX (`#5874`): Do not combine multi-arena Device-DAX L1 with P2P, NIXL, or Mooncake-over-RDMA L2 adapters that require a single contiguous L1 virtual region.
  • Uncoordinated Cross-Server CXL Offsets (`#5874`): LMCache validates overlap within one process (`st_rdev`), not across independent OS processes; operators must assign disjoint `[offset, offset+size)` slices across servers.
  • Non-Contiguous / Odd-Offset MLA Views (`#5529`): Do not invoke `_RotateTail` on non-contiguous views or odd bf16 storage offsets; keep the fallback `split -> ComplexRoPE -> cat` path for non-contiguous inputs.
  • All-Experts-Local Sentinel Assumption (`#6840`): When `num_local_experts == num_experts` (no remote shard exists), `(offset + local) % E` wraps to a local expert; rely on zero-weight masking in single-rank mode.
