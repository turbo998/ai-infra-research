UNDER THE HOOD

Row sharding reduces partial sums; column sharding reconstructs dimensions.

Synthetic pooling inputs · measured local CPU timings only · independently_reproduced=false

ROW: route IDs to row owners
     sum partial vectors across owners
     divide once by full bag count for ideal mean
COLUMN: deliver IDs to every column owner
        concatenate pieces in original dimension order
TABLE: one owner stores the whole table

↓ pinned implementation boundaries

Training RW: sparse AlltoAll → pooled ReduceScatter
TW/CW: sparse AlltoAll → pooled AlltoAll
RW/TWRW mean callback: divisor + 1e-6

subgroup members = [1,3,5,7]
global_root = members[local_root=0]  # 1, not 0
Recent first-party context: the November 11, 2026 fix maps subgroup-local root zero to a global rank before replicated-table initialization. Training and inference distributors differ.

MY TAKE

Choose ownership from table size, input replication and pooled-output pressure.

Synthetic pooling inputs · measured local CPU timings only · independently_reproduced=false

✅ Good fit

Table-wise for many suitably sized tables.

Row-wise for a table too large for one rank.

Column-wise when dimension splitting is worthwhile.

Global counts and explicit root mapping.

⛔ Not for

Local means as global means.

Dedup without multiplicity.

Wrong column reassembly.

Logical tensor bytes called wire traffic.
