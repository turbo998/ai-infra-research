4 / 7 · UNDER THE HOOD

One-Line PyTorch TF32 Enablement & cuBLAS BF16x3

# 1. Always set at training/serving entrypoint: import torch torch.set_float32_matmul_precision("high") # Enables TF32! # Equivalent to: torch.backends.cuda.matmul.allow_tf32 = True ↓ # 2. Keep 32-bit FP32 accumulation enabled (NEVER disable): torch.backends.cuda.matmul.allow_fp16_reduced_precision_reduction = False # 3. For exact 23-bit FP32 on Tensor Cores (cuBLAS 12+ Ozaki BF16x3): # CUBLAS_COMPUTE_32F_FAST_3TF32 / BF16x3 splits mantissa into 3 slices!
TF32 rounds inputs from 23-bit to 10-bit mantissa in hardware while accumulating in full FP32.
