Zero-Materialization Training & Prefill Slicing

Training / RL: Never call lm_head(h) before loss! from liger_kernel.transformers import LigerFusedLinearCrossEntropyLoss loss_fn = LigerFusedLinearCrossEntropyLoss() loss = loss_fn(model.lm_head.weight, hidden_states.view(-1, D), labels.view(-1)) ↓ # 2. Inference Prefill: Slice last token BEFORE lm_head (33,000x smaller!): last_hidden = hidden_states[:, -1:, :] # [B, 1, D] instead of [B, 32768, D] next_token_logits = model.lm_head(last_hidden)
