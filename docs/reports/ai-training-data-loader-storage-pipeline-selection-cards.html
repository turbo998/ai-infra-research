Perturbation & Consistency Analysis

1. 为什么纯文本训练不需要 DALI？ 因为纯文本在预处理阶段已经分词为紧凑的 `uint16/uint32` Token ID，读取后可直接 DMA 进显存，故 Tier 3 (`1,440 samples/s`) 已完全喂饱 GPU。

2. 为什么 1080p 视频训练必须用 DALI `NVDEC`？ 视频关键帧（I-frame）与预测帧（P/B-frame）解码涉及复杂的运动补偿与变换，H100 内置的 7 路专用硬件 `NVDEC` 引擎可在不占用任何 Tensor Core 的情况下实现 6.14 倍提速。

Robustness Conclusion: Match the preprocessing engine to the modality: `MDS/LitData` for text tokens, `MDS/LitData + NVIDIA DALI` for high-res images and video.
