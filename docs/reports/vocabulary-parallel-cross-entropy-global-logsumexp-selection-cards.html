UNDER THE HOOD

Reduce three token-wise statistics, not the full vocabulary matrix.

SYNTHETIC DEMO · independently_reproduced=false · no GPU measurements

m = MAX_r(max(local_logits_r))
s = SUM_r(sum(exp(local_logits_r - m)))
t = SUM_r(owner_r ? local_target_logit - m : 0)
loss = log(s) - t

↓ local backward with the shared global denominator

p_r = exp(local_logits_r - m) / s
grad_r = (p_r - owner_target_one_hot_r) * upstream

Mask non-real padded classes before reductions.
Apply token masking and mean normalization explicitly.
Tensor parallelism is not data parallelism. Loss values are replicated across vocabulary ranks; do not average this denominator or divide by TP size again.
