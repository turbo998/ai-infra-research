7 / 7 · MY TAKE ARCHITECT VERDICT & READINESS

Good Fit vs. Not For: Production Storage & Memory-Tiering Playbook

✅ Good Fit (When to Adopt)

  • Two-Phase Async Checkpointing (PyTorch DCP): Mandatory for all ≥128-GPU training jobs; saves $181.8K/mo on 512 GPUs by cutting stalls from 225.0 s to 3.125 s.
  • L1 Pinned Host DRAM KV Pool (LMCache / Dynamo): Best zero-network upgrade for 16K–128K multi-turn coding/RAG agents (52.0 ms TTFT, -54.2% cost).
  • L2 Shared RDMA/NVMe Pool (Mooncake / 3FS + GDS): Best for multi-node stateless routing and PD-disaggregated clusters with 400G RoCEv2/IB (62.0 ms TTFT, -50.0% cost).

⛔ Not For (When to Avoid)

  • Never use non-GDS POSIX/TCP disks for live KV Cache offload: CPU bounce buffers cap reload at ~3.2 GB/s (652.0 ms TTFT) while starving host CPUs.
  • Do not offload short prompts (<4,096 tokens) to remote storage: Recomputing 2K tokens in HBM takes <20 ms.
  • Do not enable async checkpointing on nodes with <1.5 TB Host DRAM without reserving 256–512 GB pinned memory headroom.
