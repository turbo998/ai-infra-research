7 / 7MY TAKE · GOOD FIT VS NOT FOR & PRODUCTION READINESS
Architect Verdict: Decouple Code & Weights with Nydus, Use O_DIRECT, and Broadcast Weights Over RDMA

✅ Good Fit (When to Use Tier 3 / Tier 4)

  • 16–1,024+ Node Production Rollouts & Autoscaling (Tier 4): Striped single-read + 400G RDMA broadcast eliminates storage gateway bottlenecks completely.
  • RL Actor→Rollout Checkpoint Sync (Tier 4): Broadcasts updated weights across hundreds of rollout GPUs in seconds.
  • 1–8 Node Clusters (Tier 3): Nydus lazy image + Run:ai Streamer `O_DIRECT` cuts startup by 10.6x without needing a P2P daemon.

⛔ Not For (When to Avoid)

  • Never bake >5GB model weights into Docker/OCI image layers (Tier 2): Causes catastrophic Kubelet `DiskPressure` evictions.
  • Never use default `safetensors` `mmap()` on cold network filesystems (Tier 1): Always use multi-threaded `O_DIRECT` or GDS.
