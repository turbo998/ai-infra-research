def evaluate_or_score_rl(sample, resp_a, resp_b=None):
    if sample.is_verifiable:  # 70% 企业任务：代码 / SQL / 数学 / 工具调用
        if sample.domain == "math":
            return 1.0 if sympy_equivalent(extract_boxed(resp_a), sample.gold) else 0.0
        return 1.0 if wasm_sandbox_run_tests(resp_a, sample.unit_tests).passed else 0.0

    # 30% 开放式主观任务：剥离讨好前缀 + 双向位置交换 (命中 KV Prefix Cache)
    clean_a, clean_b = strip_sycophancy(resp_a), strip_sycophancy(resp_b)
    v_ab = judge_llm(sample.question, sample.rubric_5pt, first=clean_a, second=clean_b) # 'A' or 'B'
    v_ba = judge_llm(sample.question, sample.rubric_5pt, first=clean_b, second=clean_a) # 'A' or 'B'
    if (v_ab == "A" and v_ba == "B"): raw_win = 1.0
    elif (v_ab == "B" and v_ba == "A"): raw_win = 0.0
    else: raw_win = 0.5  # 正反矛盾直接判平局，消灭 28.4% 位置偏见！
    return glm_length_debias(raw_win, len(clean_a) - len(clean_b))
# <answer> Validated: 96.8% human agreement, 0.4% position flip, 0.0% RL reward hacking
Protocol Insight: Forcing contradictory `(A,B)` and `(B,A)` judgments to `0.5 (Tie)` mathematically zeroes out first-position bias while preserving high sensitivity on true quality gaps.

✅ Good Fit (强烈推荐场景)

  • • 代码、SQL、数学财务计算、工具调用与 GRPO 强化学习 → Tier 4 (RLVR 确定性沙箱 + PRM)：96.8% 人类一致率，0.0% 刷分坍塌。
