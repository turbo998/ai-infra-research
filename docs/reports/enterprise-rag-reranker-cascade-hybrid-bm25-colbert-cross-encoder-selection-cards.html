3-Stage Funnel & Calibrated Relevance Cutoff Gate

// Stage 1: Hybrid BM25 + Dense Vector RRF (8ms)
c100 = rrf_merge(bm25.search(q, 100), dense.search(q, 100), k=60)

// Stage 2: Fast ONNX / Late-Interaction Pruner (6ms)
c25 = flashrank_or_colbert_maxsim(q, c100, top_k=25)

// Stage 3: TEI Cross-Encoder + Dynamic Cutoff (28ms)
scores = tei_cross_encoder.score(q, c25) // BGE-Reranker-v2-M3
final_chunks = [c for c, s in zip(c25, scores) if s >= 0.35][:5]
