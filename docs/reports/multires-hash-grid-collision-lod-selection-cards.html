UNDER THE HOOD

A soft forward needs the same weight in its backward.

Synthetic scalar fields · independently_reproduced=false · Original CPU timings separately measured; no native/GPU or reconstruction-quality result.

z = lod * number_of_levels + 1e-3
hard[level] = 1 if level < z else 0
soft[level] = clamp(z - level, 0, 1)
output[level] = soft[level] * raw[level]
table[index] is shared by all collided corners

↓ objective = sum(output²) / 2

dL/draw = soft² * raw
raw middle feature = 0.06486000
soft middle weight = 0.50100000
correct gradient = 0.0162799249
finite difference = 0.0162799249
table VJP: add upstream * weight for EVERY corner
Unweighted output matters. The source retains an unweighted base output and weights upstream adjoints; accidentally feeding a weighted value back to a base API can weight twice. This study does not implement the source wrapper’s LoD-input derivatives or full double backward.
