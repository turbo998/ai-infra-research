3 Kernel Contracts Eliminating Silent Corruption, Launch Overflow & Host Syncs on B200 / GB300 / SM120

“A per-row top_k tensor qualifies only through the caller's top_k_max bound: deriving the bound from top_k.max() would add a host sync on every call.” — flashinfer@ba25ff7
1. Persistent Softmax Async-Proxy Fence (flashinfer@fc4df7e) · choice Act automatically · 4000/4000 Pass (0.996x geomean)

在 mbarrier_wait(freed_addr, 0) 之后插入 fence.proxy.async.shared::cta;，隔离前一行通用代理 st.shared 与下一行 TMA cp.async.bulk 槽位重填。

2. Bounded Per-Row Tensor top_k_max Fast Path (flashinfer@ba25ff7) · score Act automatically · 3.7569x Faster (0.819 → 0.218 ms)

先通过 Radix Top-K 选出每行前 top_k_max=20 个有序候选，再按每行各自的 top_k[i] 掩码截断，零 Host-Device 同步完成采样。

3. Radix Top-K Static Shared Memory Accounting on SM120 (flashinfer@205c51e) · choice Act automatically · 558/558 Pass (99,600 ≤ 101,376 B)

扣除内核静态共享内存 attr.sharedSizeBytes = 336 B，阻止 1024 线程配置（101,312 + 336 = 101,648 > 101,376 B）在 RTX 5090 上触发 cudaErrorInvalidValue。

Key Takeaway: 在 Blackwell/SM120 上，动态共享内存预算必须严格满足 dynamic_smem + attr.sharedSizeBytes ≤ max_smem_per_block，且 TMA 重用同一 SMEM 槽位必须跨代理栅栏同步。

7 / 7 · MY TAKE Good Fit vs Not For & Readiness

Production Adoption Guide for Phase 121 Kernel, Serving & Distributed Training Upgrades

✅ Good Fit (Recommended Now)

  • Per-Row Top-K Sampling with Known Upper Bound: 在 vLLM/SGLang 传入 top_k_max（如 ≤ 64），在 128K–262K 词表上立竿见影获得 1.80x–3.76x 采样提速且零 Host 同步。
  • Long-Context Video/DiT FMHA on Blackwell: VC-attention-QK8 在 S=75.6k 上将注意力耗时压缩至 115 ms (1.44x)，适合长序列生成。
  • Heterogeneous-Width FSDP Parameter Groups: 当不开启 nccl_ub 时，megatron_fsdp_padded_shards=False 可消除最高 85.7% 的 LCM 填充显存与通信开销。
  • Realistic MoE Benchmarking: 使用 vLLM zipf_topk_ids (α=1.25) 评估 EP/All-to-All 热点不均衡。

⛔ Not For (Avoid / Guard Carefully)

  • ShardLayout.UNPADDED + nccl_ub=True: NCCL 对称内存（Symmetric Memory）要求所有 Rank 分片严格等长，开启 nccl_ub 时必须保留 ShardLayout.PADDED。
  • SM103 SMEM Residual Staging on Short Waves (waves < 8): 当 tile_pairs < 608 时，双 2 KiB 槽位预取开销无法被流水线掩盖，应保持常规路径。
  • Flat High-Entropy Probs in from_probs Top-K Fast Path: 在 rand()/sum 平坦分布且大词表高 Batch 下，from_probs 快速路径为 0.7x–0.9x，优先用于 from_logits 或尖锐分布。
