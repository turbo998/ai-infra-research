UNDER THE HOOD

Clear real endpoints after the other axes have been inversed.

SYNTHETIC · independently_reproduced=false · no GPU or PDE-quality measurements

input: real[Nx, Ny]
spectrum = rfftn(input, norm="forward")
shape = [Nx, floor(Ny/2)+1]
out[kx,ky] = SUM_c input[c,kx,ky] * W[c,o,kx,ky]

Only non-last axes use centered signed-frequency slicing.

↓ inverse the complex axes before enforcing real endpoints

rows = ifft(spectrum, axis=0, norm="forward")
rows[:,0].imag = 0
if Ny is even: rows[:,-1].imag = 0
output = irfft(rows, n=Ny, axis=1, norm="forward")

Raw 2D boundary columns can be complex across kx.
Clearing them early erases valid first-axis phase.
