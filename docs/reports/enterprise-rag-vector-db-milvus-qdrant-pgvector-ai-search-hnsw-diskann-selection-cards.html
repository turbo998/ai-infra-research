4 / 7 · UNDER THE HOOD

Vector Memory Sizing Formula & 2-Stage Rescoring

Raw FP32 = N * d * 4B = 100M * 1536 * 4 = 614.4 GB
HNSW FP32 DRAM = Raw * 1.75 = 1,075 GB
DiskANN DRAM = PQ64 Codes (~96 GB) + NVMe Vamana

Stage 1 retrieves `3 * k` candidates via RAM PQ/BQ codes; Stage 2 fetches full vectors from NVMe to rescore exact cosine similarity.

1-2 NVMe random reads (4KB aligned) add only ~4ms latency
