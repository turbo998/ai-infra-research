Why Vanilla Full-Sequence Diffusion Collapses at 16K Context While Block Diffusion Thrives

Without a block-causal mask, Tier 3 (Vanilla LLaDA) must recompute full $16,896 \times 16,896$ bidirectional attention on all 32 denoising steps—collapsing by `-80.5%` to `38.0 tok/s` (slower than naive AR!). Tier 4 (Block Diffusion) caches the 16,384 prompt tokens once and only denoises the active 128-token block, sustaining 940.0 tok/s 🏆.

Robustness Conclusion: Inter-block causal KV caching is mandatory for any diffusion LLM deployed on real-world long contexts.

7 / 7 MY TAKE · ARCHITECT DECISION GUIDANCE & PRODUCTION READINESS

Good Fit vs. Not For: Use Block Diffusion for Ultra-Fast Code/JSON & EAGLE-3 for Stock AR Weights

Practical architecture rules for next-generation LLM inference platforms.

✅ Good Fit (When to Adopt Tier 4 / Tier 2)

  • IDE Code Completion, Infilling & Instant Diff Apply (Tier 4): Delivers >1,000 tok/s (0.43s for 512 tokens) with native bidirectional context awareness.
  • Structured JSON & UI Schema Generation (Tier 4): High-confidence JSON keys/brackets converge in 4–5 parallel denoising steps.
  • Existing Unmodified AR Checkpoints (Tier 2 EAGLE-3): Best zero-retraining speedup (2.54x) for stock Llama/Qwen/DeepSeek models.

⛔ Not For (When to Avoid)

  • KV-Cacheless Full-Sequence Diffusion on Long Prompts (Tier 3): Recomputing 4K–16K prompts on every denoising step destroys throughput.
  • Unaccelerated Token-by-Token AR on Latency-Critical Coding (Tier 1): Wastes 98.2% of Tensor Core capacity waiting on HBM reads.
  • Parallel Unmasking Without Low-Confidence Remasking: Always enable remasking to prevent adjacent token collisions.

Day-1 Production Diffusion LLM Checklist

1. Enforce block-causal attention masks so prompts and completed blocks are stored in Paged KV Cache.
2. Set active block size $B = 64$ or $128$ to match GPU Tensor Core MMA tile boundaries.
3. Enable confidence-threshold early exit ($p > 0.96$) and warm-start denoising for code edits.
4. Enable low-confidence remasking between steps to maintain grammatical coherence.
