UNDER THE HOOD

Shared factors preserve averaging. Error feedback preserves a ledger.

SYNTHETIC DEMO · independently_reproduced=false · no GPU benchmark

{
  "gradient": "M_i = G_i + E_i",
  "P": "orth(mean_i(M_i Q_shared))",
  "Q_next": "mean_i(M_i^T P)",
  "output": "P Q_next^T"
}

↓ two sequential factor reductions; vectors stay dense

E_i(next) = M_i - output
mean_i(sum_t G_i,t) - sum_t output_t
  = mean_i E_i(final)   # initial E = 0

step = backward + max(0, comm + codec - overlap)
No independent local SVDs. Factors must share their basis. The telescoping identity is accounting, not convergence or loss parity.
