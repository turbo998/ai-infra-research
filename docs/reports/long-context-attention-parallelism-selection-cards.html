门控边界 1：为什么纯 Ulysses 卡在 8 卡？

70B 模型普遍采用 GQA (H_kv=8)。Ulysses 按头切分，当并行度 N > 8 时必须复制 KV 头，导致跨机通信暴涨 +300%，必须引入第二维 Ring Attention。

门控边界 2：精确无损 vs. 原生稀疏混合

存量稠密模型或法律零容忍审计选 Tier 3 (2D USP, 100.0% RULER)；新建高并发 128K–1M 服务选 Tier 4 (MLA+NSA / 3:1 GDN, 99.4% RULER, 成本省 97.1%)。

7 / 7 · MY TAKEGOOD FIT VS NOT FOR & READINESS

架构师选型裁决：何时用 2D USP 全注意力，何时上 MLA+NSA / 3:1 线性混合？

✅ Good Fit (强烈推荐适用场景)

  • 32K–128K 单机低延迟长文本：直接启用 Tier 2 (`DeepSpeed-Ulysses SP=8`)，吃满机内 NVLink，1.42s 首字响应。
  • 128K–1M 存量稠密模型或零容忍法律/金融审计：采用 Tier 3 (`2D USP = Ulysses-8 × Striped Ring-4`)，保持 100.0% 数学无损精度，1M TTFT 降至 14.60s (16.99x)。
  • 128K–1M+ 高并发在线 Agent / 全仓库编码：优选原生支持 Tier 4 (`MLA + NSA` 或 `3:1 GDN`) 的底座模型 + CP=16，1M TTFT 仅 3.20s (77.50x)，成本直降 97.1% ($0.04/req)。

⛔ Not For (严禁误用场景)

  • 严禁将纯 Ulysses 度数设大过 GQA KV 头数 (N > H_kv)：否则触发跨机 KV 头复制与 All-to-All 拥塞。
  • 严禁在自回归长文本中使用未条带化的普通 Ring Attention：Causal Mask 下三角会让前排 GPU 空转 50% 步数，必须开启 Striped / Zig-Zag。
  • 严禁在未经稀疏训练的稠密权重上强开高比例稀疏丢弃：会严重破坏长距离召回率，存量稠密权重应走 2D USP。
生产就绪度与开源生态 (Readiness & License)：
• 2D USP (`Ulysses × Striped Ring`)：已在 yunchang、Megatron-Core Context Parallelism (a2a+p2p)、vLLM / SGLang CP 中成熟开源（Apache-2.0）。
• MLA + NSA / 3:1 GDN：已在 FlashMLA、FlashInfer、vLLM / SGLang 新一代混合注意力内核中生产就绪。
• Provenance：synthetic + anonymized_reported (independently_reproduced=false, physical cluster: not_measured, local CPU verifier: measured PASS)。
