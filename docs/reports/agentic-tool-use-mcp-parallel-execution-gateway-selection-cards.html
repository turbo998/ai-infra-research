7 / 7 · MY TAKE ARCHITECT READINESS & FIT

架构师总结：什么时候用 JSON 并行调用（Tier 3），什么时候上 CodeAct（Tier 4）？

✅ Good fit (强烈推荐)
  • 多步自动化排障 / 数据分析 / 跨系统编排 (Tier 4)：启用 tool_search + CodeAct 沙箱循环 + 响应投影，3.8s 极速闭环且省钱 95.6%。
  • 每步均需人工弹窗审批的高敏写操作 (Tier 3)：启用 tool_search + 粘性 KV 驻留。
⛔ Not for (严禁踩坑)
  • 严禁把 >20 个完整 MCP Schema 硬塞进每次请求 (Tier 1)：既贵又降智。
  • 严禁把未裁剪的几十 KB 原始 REST JSON 直接塞回给大模型：必须在网关或沙箱层过滤。
