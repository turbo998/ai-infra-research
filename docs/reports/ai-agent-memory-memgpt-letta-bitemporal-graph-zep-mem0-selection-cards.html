架构师总结：Agent 记忆不是向量搜索，而是“分层状态机”

✅ Good fit (强烈推荐)
  • 企业伴随式数字员工 / 研发助手 (Tier 4)：采用 L1 常驻 Core Memory 块 (Letta) + L2 双时态知识图谱 (Zep/Graphiti) + L3 原始归档日志。
