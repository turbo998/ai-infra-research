out = torch.matmul(q, kv)                  # 68.7 GFLOPs, 0.12 ms!
// ✅ Production Pattern 2: Bottleneck-First LoRA (r = 16)
y = F.linear(F.linear(x, lora_A), lora_B)  # 2 MB intermediate!

7 / 7 · MY TAKE

Architect Verdict: Parenthesize Bottleneck Contractions Explicitly & Prefer matmul/linear Over einsum

✅ Good fit
• Linear Attention / State-Space (`Mamba2 / GLA / DeltaNet`) chunkwise contractions
• Low-rank LoRA / MLA latent projections (`(x @ A) @ B`)
• MoE token-to-expert routing projections
⛔ Not for
• Unparenthesized multi-operand chains that materialize `[B, H, S, S]` or `[D_out, D_in]`
• Calling `torch.einsum` on non-canonical `[B, S, H, D]` strides in Eager hot loops
