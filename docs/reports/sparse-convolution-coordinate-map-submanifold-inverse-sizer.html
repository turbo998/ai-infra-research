Topology is not a nonzero test.
坐标支持、行身份和数值求逆不能混为一谈。

Regular convolution 扩展活动坐标；submanifold 保留输入支持。Cached inverse 反转历史边，不等于重新生成 transpose support，也不意味着恢复输入数值。

边界：活动行数和有效边数是 synthetic 输入，不从 occupancy 猜测。采用共享声明 grid volume 比较 payload，不推断 stride 后形状。

Native [2,K,N] 只代表所查一路径；不是 implicit GEMM masks/workspace。64-bit hash keys 不代表 pair row IDs 全变宽；不含实际 allocator、排序临时区、peak HBM。
