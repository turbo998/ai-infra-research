2 / 7 · SCENARIO: BLACKWELL & RUBIN KERNEL + KV LIFECYCLE DEEP DIVE · 3 QUANTIFIED DECISIONS

3 Stack-Wide Fixes Eliminate 101.5 ms KDA Host Stalls, 32-Bit Stride Overflow at T=42,800 & BF16 Gate Vanishing

"Through the default entry, the lean arena and batched-document options synchronized the host, so each step waited behind work already queued on the GPU... In attnResBlock, source * block_stride_r overflows 32-bit int when num_tokens * hidden_dim * (N-2) > INT_MAX."
1. FlashInfer `cake_kda_train` Plan Cache + Non-Blocking Arena (`bd60c11809`) & Softmax Balanced Chunks (`f4be6e9df5`) choice · Act automatically · 98.4%

Caches `plan()` on `(S, num_docs, H, sm_count, arch)` (`1.044 ms → 0.0016 ms`, `63 → 0` record selections) and replaces host tensor builds with device `arange` + `non_blocking=True` pinned copies (`6 → 0` host syncs, cutting wait behind a 98 ms spin from `105.88 ms` to `4.33 ms`). In `cake_softmax`, `ceil(vocab/CTAs)` rounded to 32 cuts per-CTA elements on `67×81928` from `12,288` to `10,272` (`10.37 → 9.50 us`, `1.094x`).

2. vLLM P2P `_retained` Source Pins (`a1cfd2c1b5`), DSA Indexer Reserve (`317081fb6d`) & TRT-LLM 64-Bit Stride (`e2b1544160`) noul · Act automatically · 96.8%

Holds source KV block pins in `_retained` up to `_RETAINED_HOLD_CAP_S = 30.0 s` after `cancel(mode="wait")` until `poll_retired()` confirms DMA stop; reserves `64.0 MiB` FP32 decode indexer logits (`256×65536×4B`) during DSA memory profiling; promotes Kimi-K3 `block_stride_r` to `long long` so `7 * 42800 * 7168 = 2,147,532,800` does not wrap to `-2,147,434,496`.

3. Megatron-LM GDP FP32 Sigmoid (`a296523510`), VeOmni FSDP2 Offload (`b65da71c17`) & Mooncake EFA Stall Floor (`3a05eec5ef`) score · Act automatically · 95.5%

Computes `b.float().sigmoid().to(b.dtype)` so autograd saves FP32 sigmoid values (`grad = 0.00384602` at `b=6.25` vs `0.0` in BF16); forwards `override_optimizer_config` under FSDP2 CPU offload to avoid a `130.39 GiB` host FP32 temp buffer on 35B models; requires both `1,024` stalled waves and `1,000 ms` (`MC_EFA_STALL_MIN_MS`) before EFA QP reset.

Architectural Takeaway: Long-context hybrid attention (KDA, GDN, Mamba2 SSD, Kimi-K3 AttnRes, GatedDeltaProduct) requires 64-bit pointer arithmetic above 42.8K tokens, FP32 autograd saves on saturating gates, and zero host synchronizations inside per-step workspace arenas.

7 / 7 · MY TAKE GOOD FIT VS NOT FOR & READINESS

Architectural Guidance: Where Phase 124 Optimizations Deliver Immediate ROI vs Anti-Patterns

✅ Good fit

  • Packed-Document KDA & GDN Training on GB200/GB300: Reusing cached `plan()` and non-blocking `KdaArena(lean=True, tail_passes=4)` eliminates `100+ ms` host stalls behind GPU compute while keeping post-step resident arena memory at `0 B`.
  • Blackwell (`sm_100a`/`sm_103a`) & Rubin (`sm_107a`) Serving: Enabling 148/152-CTA cap rules on grouped FP8 SwiGLU quant, `2x2` multicast FP4 GEMM (`M=1793..2048`), and 32-aligned softmax chunks (`48K–201K` vocab) unlocks 3–13% kernel speedups with zero kernel code bloat.
  • Disaggregated & P2P RDMA KV Offloading: Using vLLM `_retained` source pins (`cancel(mode="wait")`) and SGLang `disagg_transfers_in_flight` allocator guards prevents silent DMA memory corruption during peer disconnects or page compaction.
  • Long-Context (`T ≥ 42.8K`) & Deep mHC Training: Promoting 32-bit strides to `int64_t` in TRT-LLM Kimi-K3 `attn_res`, casting Megatron GDP sigmoid gates to FP32, and dropping mHC `dY` references per layer (`-29.29 GiB` on 60L) prevent crashes, dead gates, and OOMs.

⛔ Not for

  • Capturing Unwarmed Batched `doc_lengths` in CUDA Graphs: `cake_kda_train` intentionally refuses CUDA-graph capture of batched calls unless `doc_lengths` was copied via a caller-owned workspace run once before capture.
  • Kernel-Alone Benchmarking of PDL-Tuned Kernels: Evaluating PDL-regime routes (such as `cake_muse_spark_norm` at `M=192–224`) in isolated single-kernel launches hides the predecessor-overlap benefit (`1.1360x` in graph replay vs `0.8695x` alone).
  • ComfyUI SGLDiffusion Without `--disable-cuda-malloc`: Running ComfyUI with its default async CUDA allocator forces CPU round-trips instead of zero-copy CUDA IPC (`SGLDWorkerStatus` flags this as degraded).
  • Sub-2 MiB Unaligned Buffers on Ascend HCCS: Mooncake now strictly rejects device memory registrations not aligned to `2 MiB` (`2,097,152 B`) rather than deferring failure to asynchronous HCCS DMA faults.
