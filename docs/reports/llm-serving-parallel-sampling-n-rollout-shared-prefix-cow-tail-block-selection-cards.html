4 / 7 · UNDER THE HOOD

PagedAttention Tail-Block Copy-on-Write (`CoW`) Protocol

// When appending token at pos = 4005 (block_idx = 250, slot_idx = 5): phys_block = seq.block_table[-1] if phys_block.ref_count > 1: // Copy-on-Write: allocate private block & copy filled prefix slots 0..4 new_block = block_allocator.allocate() copy_kv_slots(src=phys_block, dst=new_block, num_slots=5) phys_block.ref_count -= 1 seq.block_table[-1] = new_block
↓ Safe Decode Write (<answer>)
// Now seq.block_table[-1].ref_count == 1! // Write slot 5..15 into private new_block without corrupting siblings!
Copies only 5 slots (0.05 ms) while keeping 4,000 prefix tokens shared.
