Counts, not ranks, set the mean.
跨 rank 均值按 observation 数加权。

Count-weighted local variance 仍缺 between-mean correction。Global forward 必须配套 global backward sums；empty rank 数值上无贡献，不等于可以跳过 collective。

边界：每通道计数包括 batch 与 spatial positions。Stats format 固定 4/8 bytes，分别检查 float count 能否精确表示与保存的 int32 count 是否溢出。

原始模型使用 Python M2，不模拟 native invstd 重建、mixed precision、CUDA Graph empty-rank path 或 DDP scaling。Buffers 不等于 wire bytes、实测 latency 或 peak HBM。
