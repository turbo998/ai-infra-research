Production Adoption Guidance for Solution Architects

✅ Good Fit

  • 低延迟单 Token 解码与高频算子调度：启用 SM100/SM103 Fence-Warp AllReduce（`c3cdc2e`）、行跨步 FlashKDA（`6028115`）与 TRT-LLM Runtime Fast-Path Hooks（`cac367c`）。
  • 多轮长上下文前缀缓存与混合量化 MoE：启用 `gfx950` DSv4.1 SWA 前缀重放（`138dfa5`）与 Quark MXFP8 共享专家槽隔离（`16a3bf3`）。
  • 高并发 RDMA KV 传输与多 NUMA 节点：启用 Mooncake RDMA 切片-投递流水线（`ab2472f`）、Dynamo ZMQ 校验重放（`4cfde0e`）与 NIXL VMM 局部性域绑定（`8456f70`）。

⛔ Not For

  • 无前缀复用的单轮随机短请求：当 Prefix Cache 命中率为 0 时，DSv4.1 SWA 重放（`138dfa5`）不触发。
  • 非 `gfx1151` 的 Quark MXFP4 W4A16 EP>1 路径：必须遵循 `fb33962` 的硬件架构门控约束。
  • 单分片极小消息的 RDMA 传输：当请求仅含单个 Slice（$K=1$）时，切片-投递流水线（`ab2472f`）无多片重叠空间。
