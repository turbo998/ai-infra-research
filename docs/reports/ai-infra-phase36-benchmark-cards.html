7 / 7 · MY TAKE · GOOD FIT VS NOT FOR & READINESS ARCHITECT DECISION GUIDE

Adopt Uncached-Token Routing & Bounded In-Flight Resharding Now; Respect Context Caps & GIL Quarantine Rules

架构师选型建议：明确适用场景（Good Fit）、禁用边界（Not For）与生产就绪度。

✅ Good Fit (推荐采用场景)

  • Hybrid SSM/Conv1D Training (`C >= 512 / 1024`): Route wide-channel causal Conv1D backward passes to 8-token staged TMA2D 2-CTA/SM kernels while pre-allocating workspace via workspace_record(arch).
  • Prefix-Heavy Disaggregated Prefill: Enable --policy cache_aware --route-by-uncached-tokens in sgl-router so long prompts with high cache hit rates land on short-extend buckets and spill only to truly idle DP ranks.
  • Multi-Endpoint Weight Resharding: Set max_inflight_batches = 4..8 with submit_scatter_read/write to overlap RDMA scatter transfers across endpoints.
  • Hierarchical KV Observability: Separate lookup_hit / lookup_requested (LMCache tier efficiency) from lookup_request_hit / lookup_prompt (whole-prompt coverage).

⛔ Not For (不适用或需规避边界)

  • Lazy JIT Inside CUDA Graph Capture: Never capture a CUDA Graph on a single channel shape without first building all architecture programs via cake_jit.specs_for_arch(arch).
  • DSV4 DSpark Attention on SM107: Only the plain SIMT CuTe fused RMSNorm+RoPE kernel supports SM107; DSV4 DSpark attention remains gated to SM100 / SM103.
  • Active Parametrization During Meta Inspection: Never inspect FSDP shard placements while ReplicateComputation is active on meta tensors.
  • Dropping Unfinished Native Transfer Tickets: Never drop references to undrained ScatterTransferTicket objects or close resource-owning batch generators before terminal drain.
