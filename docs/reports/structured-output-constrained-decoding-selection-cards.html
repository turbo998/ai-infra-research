Perturbation & Consistency Analysis

1. 为什么 Tier 3 在 BS=1 时很快 (`9.95ms`)，到 BS=128 却翻倍至 `19.60ms`？ 因为 Python 主线程同步为 128 个请求串行查表 (`128 × 0.06ms ≈ 7.7ms`) 阻塞了下一步 GPU Kernel Launch；而 `XGrammar` 用 C++ 线程池在 GPU 执行前一步的 9.5ms 窗口内异步并行完成掩码准备。

2. 复杂递归语法（Text-to-SQL / AST）鲁棒性：只有支持下推自动机（PDA）的 Tier 4 能无损处理任意层级的括号嵌套与 SQL 子查询语法。

Robustness Conclusion: Asynchronous C++ mask overlap (`XGrammar`) is mandatory for maintaining sub-10ms TPOT at production batch sizes (`BS >= 32`).
