UNDER THE HOOD

Exclusive termination can omit more color than its next-T threshold.

Synthetic RGB/geometry · independently_reproduced=false · Original CPU timings separately measured; no gsplat/GPU or image-quality result.

alpha = min(.99, opacity * exp(-sigma))
skip if sigma < 0 or alpha < 1/255
next_T = T * (1 - alpha)
if next_T <= 1e-4:
    stop BEFORE committing this Gaussian
color += T * alpha * RGB
T = next_T
color += remaining_T * background  # after the loop

↓ three .98-opacity RGB layers, black background

pre-stop T = 0.000400
exact blue = 0.000392
exclusive blue = 0.000000
omitted blue exceeds 1e-4
For bounded unit RGB, use pre-stop T as the tail bound.
Do not generalize this bound to unbounded/HDR features.
Gate order is meaningful. Since the current Gaussian is excluded, hypothetical next_T is not a bound on all omitted color. The retained T also controls output alpha/background.
