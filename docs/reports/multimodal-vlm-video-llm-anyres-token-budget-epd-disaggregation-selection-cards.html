Exact `NaViT / AnyRes` Visual Token Equations

# 1. Image Visual Token Count (14x14 ViT + 2x2 Spatial Merger = 28x28)
N_vis_img = ceil(H / 28) * ceil(W / 28)
# 1920x1080 -> 69 * 39 = 2,691 tokens; 3840x2160 -> 10,764 tokens!

# 2. Video Visual Token Count (2:1 Temporal 3D Patch Merger)
N_vis_vid = ceil((Duration_s * FPS) / 2) * N_vis_frame
1 minute of 2 FPS 720p video = `(60*2/2) * 1,216 = 72,960` visual tokens (`11.4 GB` KV!)
