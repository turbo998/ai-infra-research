Persistent Pinned Pool & Dual H2D/D2H Streams

# 1. Pre-allocate persistent Pinned Host Pool ONCE at startup: pinned_pool = torch.empty((pool_gb * 1024**3,), dtype=torch.uint8, pin_memory=True) stream_h2d = torch.cuda.Stream() # Binds to Hardware Copy Engine 0 stream_d2h = torch.cuda.Stream() # Binds to Hardware Copy Engine 1 ↓ # 2. Simultaneous Full-Duplex KV Prefetch (H2D) & KV Evict (D2H): with torch.cuda.stream(stream_h2d): gpu_kv_in.copy_(pinned_slice_in, non_blocking=True) # 54.2 GB/s with torch.cuda.stream(stream_d2h): pinned_slice_out.copy_(gpu_kv_out, non_blocking=True) # +54.2 GB/s!
Using two distinct CUDA streams lets CE0 (H2D) and CE1 (D2H) run in parallel over full-duplex PCIe.
