7 / 7 · MY TAKEGOOD FIT VS NOT FOR & READINESS

Production Adoption Guide for Phase 52 Kernel, Runtime, and Distributed Storage Upgrades

✓ Good Fit

  • Hopper/Blackwell Video & Long-Context Inference: Deploy `cake_vsa_sm90`, `cake_fused_qk_rope_{fp8_}append`, and one-wave DCP decode (`#6122`) for immediate `1.04x–1.25x` kernel speedups.
  • AMD MI350X/MI355X (`gfx950`) Disaggregated Serving: Enable `MOONCAKE_DISABLE_HIP_DMABUF=1` (`#45519`) to route KV registration via `ibv_reg_mr` and eliminate stream-creation segfaults.
  • Large-Scale MoE & TP Training: Enable TE `zero_tensor_dummy_wgrad` (`#3670`), `return_argmax=True` (`#3671`), and TorchTitan `_pending_hf_state` (`#5501`).

&⛔; Not For

  • Non-FP8 Quantized Custom-Mask Contexts in TRT-LLM: `TritonCustomMaskFmha` (`#20387`) supports unquantized and `FP8` KV caches, but explicitly rejects `INT8` and `NVFP4` KV caches.
  • Cross-PCIe Software Atomics on NIXL UCX Proxy: `nixl::ucx::proxyEngine` (`#2327`) requires NIC atomic support on GPU memory (`ucx_error_handling_mode=none`); software atomic fallback on GPU memory is unsupported.
  • Shared-Directory Multi-Client Mooncake LOCAL_DISK: Requires one client per `storage_path` under `.mooncake_local_disk.lock`.
