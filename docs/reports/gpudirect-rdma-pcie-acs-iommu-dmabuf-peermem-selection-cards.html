4 / 7 · UNDER THE HOOD PCIE ACS REGISTER & DMABUF API

底层内幕：在线热关闭 PCIe ACS 寄存器与开启 Linux 原生 DMABUF

# 1. 检查所有 PCIe Bridge 是否错误开启了 ACS 重定向 (若含 ReqRedir+ 则 P2P 被劫持!): lspci -vvv | grep -E "PCI bridge|ACSCtl" # 2. 在线关闭所有 PCIe Switch 的 ACS 拦截 (无需重启服务器，立即生效恢复 48.4 GB/s!): for bdf in $(lspci -d "*:*:0604" | awk '{print $1}'); do setpci -v -s $bdf ECAP_ACS+0x6.w=0000 done
↓ Linux 原生 `DMABUF` 替代 `nvidia-peermem` 的内核调用链 (`<answer>`) ↓
# 3. 为什么 DMABUF 比 nvidia-peermem 更稳？ # - 旧版 nvidia-peermem 通过私有符号 ib_register_peer_memory_client 强耦合 OFED 与 GPU 驱动； # - 现代 DMABUF: CUDA 调用 cuMemGetHandleForAddressRange(..., CU_MEM_RANGE_HANDLE_TYPE_DMA_BUF_FD) # 导出标准 Linux fd -> rdma-core 调用 ibv_reg_dmabuf_mr() 直接完成 BAR1 物理页映射!

7 / 7 · MY TAKE ARCHITECT READINESS & FIT

架构师总结：交付验收必查 `ACSCtl`、`iommu=pt` 与 `DMABUF`

✅ Good fit (强烈推荐)
  • 裸金属千卡/万卡集群 (Tier 4)：安装 nvidia-open 驱动 + 开启 NCCL_DMABUF_ENABLE=1 + 关闭 PCIe ACS + 配置 iommu=pt。
  • 开机自检 Systemd 服务：固化 setpci ECAP_ACS+0x6.w=0000 脚本防止 BIOS 重置。
⛔ Not for (严禁踩坑)
  • 严禁仅看 `nvidia-smi topo -m` 显示 `PIX` 就认为流量一定走 PCIe Switch 直通（必须验证 `ACSCtl` 寄存器）。
  • 严禁在闭源 `nvidia.ko` 驱动上强行开启 `DMABUF`（需使用 `nvidia-open`）。
