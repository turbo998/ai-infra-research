Under SWA replay, vLLM floors external hits to block boundaries (`2` blocks = `8` slots). LMCache aligns `12 -> 8` tokens (`(ret - 1) // 4 * 4`) and releases the lookup lock on `[8, 12)` instead of overflowing by `4` tokens.

Incrementing `notify_send_wr_id_` only after `ibv_post_send()` succeeds keeps `wr_id = 255` after a failed post, preventing wrap-around `256 % 256 == 0` from overwriting in-flight slot `0`.

7 / 7 · MY TAKE GOOD FIT VS NOT FOR & READINESS

Architectural Adoption Guide: Where Phase 66 Patterns Deliver Immediate Production Value

✅ Good Fit (Adopt Immediately)

  • Chunked-Prefill & Static-Shape Serving: Reuse `_CudnnPrefillPlan` descriptors with private detached views to cut host `plan()` latency by `13.9–14.9%`.
  • Blackwell/Hopper MXFP8 & GGUF MoE: Always compute E8M0 reciprocal scales via `exp2f_rcp(fp8SFVal)` and use `mul.rn.f32` under `-use_fast_math` to prevent subnormal flush `NaN`s.
  • ROCm Long-Context & Speculative Decoding: Share a single `get_rope()` FP32 cache sized to `max_model_len` across target layers (`512×` VRAM reduction).
  • CUDA-Graphed FP8/FP4 Dynamic Inference: Zero padding rows via a device-resident `real_token_count` pointer (`zero_padding_rows_kernel`) rather than frozen Python slices.
  • SWA Prefix Replay + Disaggregated KV: Align full-prompt external KV hits to chunk boundaries (`(ret - 1) // chunk * chunk`) and advance RDMA `wr_id` strictly after `ibv_post_send()` succeeds.

⛔ Not For / Known Guardrails

  • GPU-Controlled `skip_fp8_weight_update` Tensors: TE `torch.compile` FP8 weight caching supports `is_first_microbatch` booleans, but tensor-driven `skip_fp8_weight_update` and `fuse_wgrad_accumulation=True` still require eager mode.
  • Draft Models Exceeding Target `max_model_len`: In vLLM Muse Spark, draft layers (`is_draft=True`) must retain `max(config.max_position_embeddings, max_model_len)` and separate dtype rules rather than sharing the target FP32 RoPE cache.
  • PyTorch `expandable_segments:True` with Legacy CUDA IPC: Mooncake `IntraNodeNvlinkTransport` requires `cudaMalloc`/`cuMemAlloc` buffers and shared container PID namespaces (`--ipc=host --pid=host`); `cuMemCreate` VMM buffers cannot export `cudaIpcMemHandle_t`.
  • Expired Request-Drain Deadlines: `VLLM_WORKER_SHUTDOWN_TIMEOUT_SECONDS` only applies when `request_timeout == 0 and process_timeout == 0`; it will not extend an expired request-draining window.
