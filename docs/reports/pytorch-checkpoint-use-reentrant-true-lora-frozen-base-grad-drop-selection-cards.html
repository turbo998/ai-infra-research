4 / 7 · UNDER THE HOOD

`use_reentrant=False` + Selective Checkpoint Policy (`SAC`)

from torch.utils.checkpoint import ( checkpoint, CheckpointPolicy, create_selective_checkpoint_contexts ) def policy_fn(ctx, op, *args, **kwargs): if op in (torch.ops.aten.mm.default, torch.ops.aten._scaled_mm.default): return CheckpointPolicy.MUST_SAVE # Never recompute heavy GEMMs! return CheckpointPolicy.PREFER_RECOMPUTE # Recompute FlashAttn & SwiGLU!
↓ Graph-Preserving `use_reentrant=False` Execution (<answer>)
out = checkpoint( layer, hidden_states, use_reentrant=False, context_fn=functools.partial(create_selective_checkpoint_contexts, policy_fn), )
Saves 72.0% of activation memory while costing only +4.8% step time!
