2D HSDP Mesh & Intermediate Micro-Batch Control

# 1. Build 2D HSDP DeviceMesh (Inter-Node Replicate × Intra-Node Shard): mesh_2d = init_device_mesh("cuda", (num_nodes, 8), mesh_dim_names=("rep", "shard")) fully_shard(model, mesh=mesh_2d) ↓ # 2. Across GAS=8 micro-batches, keep intra-node RS active (17.5 GB) # and trigger inter-node AllReduce ONLY on the final micro-batch: for mb in range(gas_steps): is_last = (mb == gas_steps - 1) model.set_reshard_after_forward(is_last) loss = model(batch[mb]); loss.backward()
Intra-node 900 GB/s NVLink handles per-micro-batch sharding while 50 GB/s RoCE stays quiet until MB 8.
