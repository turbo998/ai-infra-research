4 / 7 · UNDER THE HOOD

Incremental Aho-Corasick DFA State & Prefix-Overlap Holdback

// 1. Advance DFA only on newly decoded token text delta for ch in new_token_str: dfa_state = ac_automaton.step(dfa_state, ch) if ac_automaton.is_match(dfa_state): return truncate_at_stop(pending_buf + new_token_str)
↓ Dynamic Prefix-Overlap Holdback (<answer>)
// 2. Hold back ONLY longest stop-string prefix overlap p p = ac_automaton.depth(dfa_state) # p == 0 on normal text! candidate = pending_buf + new_token_str emit_to_sse = candidate[:len(candidate) - p] pending_buf = candidate[len(candidate) - p:]
Zero lag when p == 0; zero partial leak when p > 0.
