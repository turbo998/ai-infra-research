4 / 7 · UNDER THE HOOD

The 3-Watermark GPU Sizing Equations

# Watermark 1: Fits in HBM (Use P_total for MoE!)
M_KV = B * S * (2 * L * n_kv * d_h * bytes_kv) # or MLA: L*576*B_kv
N_mem = ceil((P_total*bytes_w + M_KV + M_act) / (0.85 * HBM_gpu))

# Watermark 2: Meets TPOT SLA (Use P_active for MoE!)
N_bw = ceil((P_active*bytes_w + M_KV_step) / (TPOT * BW_gpu * MBU))
N_GPU = max(N_mem, N_bw, N_compute_prefill)
Always round `N_GPU` up to a power-of-2 `TP` degree (`1, 2, 4, 8`) inside NVLink
