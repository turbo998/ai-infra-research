✅ 为什么卸载必须用 `cudaMallocHost` 锁页内存池？
普通 `malloc` 分页内存无法被 GPU 硬件 DMA 引擎直接访问，会导致 `cudaMemcpyAsync` 退化为同步阻塞 CPU 拷贝；预分配环形锁页池才能跑满 56 GB/s 零阻塞！
✕ 为什么不能把 AllGather 后的 FP16 权重存在激活里？
FSDP 与激活重计算配合时，反向重算前应通过异步 `AllGather` 重新拉取分片权重，绝不在激活检查点中重复保存整份未分片权重！
Matrix Summary: Replacing Full Checkpointing (Tier 2) with SAC + Async Offload (Tier 4) cuts recompute overhead from +33.3% to +2.8% and boosts cluster throughput from 148.5k to 195.2k tok/s.

SAVE_OPS = {torch.ops.aten.mm.default, torch.ops.aten.addmm.default, torch.ops.aten._scaled_mm.default}

def sac_policy_fn(ctx, op, *args, **kwargs):
    # 昂贵的线性层 GEMM (97.2% 算力, 29.4% 显存) 强制保留；SwiGLU/Norm/RoPE (2.8% 算力, 70.6% 显存) 重算！
    return CheckpointPolicy.MUST_SAVE if op in SAVE_OPS else CheckpointPolicy.PREFER_RECOMPUTE

# 2. Tier 4: 前向异步卸载至 Host Pinned DRAM + 反向提前 1 层流水线预取 (0.0ms 阻塞)
def async_offload_saved_gemm_hook(tensor_gpu: torch.Tensor, layer_id: int) -> Handle:

    with torch.cuda.stream(d2h_dma_stream):  # 走硬件 Copy Engine，占用 0 个 GPU SM！
