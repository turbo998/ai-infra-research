Shard ownership, not the pooling contract.
分片所有权，不偷换 pooling。

三种分法：TW 整表驻留一个 owner；RW 分行合并 partial；CW 分列并按原顺序拼接。均值应按完整 bag 计数；重复 ID 是重复贡献。

固定源码 RW/TWRW mean callback 使用 count + 1e-6，不冒充理想均值的 bitwise 等价。

口径：单表、等宽区间分片的最大权重块；logical ID delivery 含本地投递，partial bytes 是物化量，不是实际网络发送字节。未计 offsets/lengths、优化器、激活、通信拓扑或访问倾斜。
