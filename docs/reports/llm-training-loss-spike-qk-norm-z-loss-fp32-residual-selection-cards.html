4 / 7 · UNDER THE HOOD QK-NORM, Z-LOSS & FP32 RESIDUAL

底层内幕：三重数值防弹衣的核心代码与数学上界证明

# 1. Per-Head QK-Norm (在 RoPE 旋转前将每个头的 Q 和 K 向量归一化，O(N) 融合!): q = rms_norm_per_head(q, weight=q_norm_w, eps=1e-6) # ||q||_2 == sqrt(d_head) k = rms_norm_per_head(k, weight=k_norm_w, eps=1e-6) # ||k||_2 == sqrt(d_head) # 由柯西-施瓦茨不等式: |q * k^T| / sqrt(d_head) <= ||gamma_q||_inf * ||gamma_k||_inf * sqrt(d_head)
↓ `FP32` 主残差流 + `PaLM / DeepSeek z-loss` 防漂移公式 (`<answer>`) ↓
# 2. FusedAddRMSNorm: 残差主干 residual 始终保持 FP32，仅将归一化输出 x_norm 转为 BF16/FP8: residual_fp32 = residual_fp32 + sublayer_out_bf16.float() x_norm_bf16 = rms_norm_fp32(residual_fp32).to(torch.bfloat16) # 3. Auxiliary z-loss (惩罚 Softmax 分母 log(Z) 偏离 0，防止输出层/MoE 路由器 Logit 漂移): z_loss = 1e-4 * torch.mean(torch.logsumexp(logits_fp32, dim=-1) ** 2)

7 / 7 · MY TAKE ARCHITECT READINESS & FIT

架构师总结：现代大模型训练必配“三重数值防弹衣”

✅ Good fit (强烈推荐)
  • 所有新建 Dense / MoE / 多模态预训练与大跨度续训 (Tier 4)：启用 Per-Head QK-Norm + FP32 残差流 + 1e-4 z-loss。
  • 算子融合实现：将 `QK-Norm` 与 `RoPE` 融合为单个 Triton/CUDA 内核。
⛔ Not for (严禁踩坑)
  • 严禁在 >32 层模型上使用纯 `BF16` 累加主残差流（必须在 Megatron/TorchTitan 开启 `--fp32-residual-connection`）。
  • 严禁在新模型设计中继续采用高开销的 $O(N^2)$ `Attention Tanh Soft-Capping`。
