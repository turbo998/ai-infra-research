Stochastic Rounding vs Kahan Compensated BF16 Kernel

// 1. Stochastic Rounding (Philox 16-bit noise in FP32-to-BF16 cast): uint32_t bits = __float_as_uint(w_fp32_new); uint32_t rand16 = philox_urandom16(seed, idx, step); bf16 w_sr = __ushort_as_bfloat16((bits + rand16) >> 16); ↓ // 2. Kahan Compensated BF16 Update (Deterministic & Zero-Variance): float y = -lr * update - kahan_c[i]; float t = (float)w_bf16[i] + y; bf16 w_next = __float2bfloat16_rn(t); kahan_c[i] = (bf16)(((float)w_next - (float)w_bf16[i]) - y);
Blackwell (SM100) also introduces native PTX hardware stochastic rounding instructions.
