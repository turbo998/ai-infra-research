UNDER THE HOOD

Lowering scale groups signed indices by mathematical floor.

base = 2 ** (2 ** -scale)
bucket i means (base**i, base**(i+1)]
scale <= 0, exact rational observation:
i = (ceil(log2(value)) - 1) // 2**(-scale)
zero -> separate counter
exact power-of-two boundaries stay upper-inclusive

↓ no floating logarithm in the original bounded model

downscale delta levels:
    new_i = floor(old_i / 2**delta)
    new_count[new_i] += old_count[old_i]
merge: align to a common coarser scale, then SUM
fit: lower scale until logical span <= max_size
never reconstruct finer buckets from coarse counts
Original arithmetic, not copied SDK code. Native Go uses exponent/fraction mapping and signed shifts; source merge has locking/mutation requirements not reproduced by immutable Python states.
