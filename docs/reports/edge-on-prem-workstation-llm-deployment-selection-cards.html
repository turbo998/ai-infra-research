Perturbation & Consistency Analysis

1. 为什么 4×4090 在 16→32 人时吞吐反而从 245 掉到 210 tok/s？ 因为 20GB 剩余显存最多只能容纳约 18 个 16K 上下文会话的 KV Cache；第 19～32 个会话到达时，vLLM 被迫频繁触发 Preemption（丢弃重算或 PCIe Swap），造成吞吐雪崩。

2. 单机跑 235B / 405B FP4 模型能力：Tier 3 (`192GB`) 与 Tier 4 (`282GB`) 均可单机完整装下 405B FP4 (`~205GB`) 或 235B FP8，而 4×4090 (`96GB`) 完全无法加载。

Robustness Conclusion: VRAM capacity headroom above model weights (`116 GB` on Tier 3 vs `20 GB` on Tier 1) is the decisive factor for multi-user on-prem throughput.
