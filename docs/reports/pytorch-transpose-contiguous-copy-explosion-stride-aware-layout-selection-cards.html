7 / 7 · MY TAKE

Architect Verdict: Use Strict .view(), Keep stride(-1)==1 & Ban .transpose().contiguous()

✅ Good fit
• All Transformer pre-training, SFT, and inference attention blocks
• Long-context (`32K–128K`) workloads where activation HBM is bottlenecked
• Custom Triton / FlashAttention / CUTLASS kernel pipelines
⛔ Not for
• Calling .transpose(1, 2).contiguous() before/after attention
• Using .reshape() to silence non-contiguous `.view()` errors
• Transposing the innermost dimension (`stride(-1) != 1`) before GEMM/Attention
