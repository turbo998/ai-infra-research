4 / 7 · UNDER THE HOOD

CUDA Driver VMM Virtual-Physical Decoupling Flow

// 1. Reserve permanent virtual address (used by CUDA Graph): cuMemAddressReserve(&va_ptr, size, align, 0, 0); ↓ // 2. On sleep(level=1/2): Unmap & release physical HBM! cuMemUnmap(va_ptr, size); cuMemRelease(phys_handle); // Frees 79.4 GB HBM; va_ptr stays valid! ↓ // 3. On wake_up(): Allocate fresh physical HBM & map to SAME va_ptr: cuMemCreate(&new_phys_handle, size, &prop, 0); cuMemMap(va_ptr, size, 0, new_phys_handle, 0);
Existing CUDA Graphs replay immediately against the remapped physical HBM.

Good Fit vs Not For & Production Readiness
