7 / 7 · MY TAKEARCHITECTURAL GUIDANCE & READINESS

Production Deployment Playbook: When to Adopt Elastic VMM Engram, Megatron HFSDP & CX8 Data Direct

Actionable decision boundaries for AI infrastructure solution architects.

✅ Good Fit

• 100 GiB–1 TiB Parametric Memory (Engram / RAG Tables): Use `HybridElasticSymmetricMemory(use_cpu_rdma_storage=True)` + `pidfd_getfd` VMM mapping to offload shards to pinned Host NUMA DRAM (`16 GiB/GPU` HBM saved) while retaining `33.56 us` warp-coalesced `gin.get` latency.

• Multi-Node Hybrid MoE/Mamba Training (64+ Nodes): Use Megatron `HFSDP` (`optim_grads_params` inner NVLink + `optim` outer IB) with `--use-nccl-ub --megatron-fsdp-max-pool-double-buffer --fp8-param-gather` to cut state memory `4.79×` vs HSDP and reduce AG/RS SM usage to `0/4` SMs.

• ConnectX-8 800G Disaggregated KV Serving: Pair GPUs and CX8 NICs by matching `firstPciRootSegment` via `mlx5dv_get_data_direct_sysfs_path@MLX5_1.25` and register contiguous non-overlapping KV pools so `BatchRdmaDeviceCache` hits `99.976%` (`0.779 ms` for `64 MiB`).

⛔ Not For

• Combining `nccl_ub=True` with `expandable_segments:True`: Incompatible with `torch.cuda.MemPool` persistent virtual addresses required by NCCL user buffer registration.

• Uncoalesced Sub-Kilobyte GPU IBGDA Reads: Issuing per-thread `512 B` `gin.get` without `ncclGinOptFlagsAggregateRequests` saturates PCIe MMIO doorbells (`305.68 us` vs `33.56 us`).

• Cross-PCI-Root CX8 `MLX5DV_REG_DMABUF_ACCESS_DATA_DIRECT`: Attempting Data Direct DMA-BUF registration on a GPU under a different PCI root (`pci000a:00` vs `pci0009:00`) fails immediately with `ENOTSUPP`; NUMA-level matching alone is insufficient when a socket hosts multiple PCI roots.
