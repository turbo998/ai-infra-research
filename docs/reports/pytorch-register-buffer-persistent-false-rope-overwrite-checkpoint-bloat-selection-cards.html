Why Default register_buffer Overwrites RoPE Theta vs. persistent=False

// ⛔ Anti-Pattern: Default persistent=True saves & overwrites inv_freq!
class RotaryEmbedding(nn.Module):
    def __init__(self, dim, theta=500_000.0):
        super().__init__()
        inv_freq = 1.0 / (theta ** (torch.arange(0, dim, 2).float() / dim))
        self.register_buffer("inv_freq", inv_freq) # Default persistent=True!
# Later: model.load_state_dict(ckpt_from_8k_base_with_theta_10000)
# ⛔ Silently overwrites self.inv_freq back to theta=10,000!
↓ Non-Persistent Buffer + Legacy Key Filter ↓
// ✅ Production Pattern: persistent=False + strip legacy inv_freq keys
class RotaryEmbedding(nn.Module):
    def __init__(self, dim, theta=500_000.0):
        super().__init__()
        self.dim = dim; self.theta = theta
        self.register_buffer("inv_freq", self._compute(), persistent=False)
    def _compute(self, device=None):
        return 1.0 / (self.theta ** (torch.arange(0, self.dim, 2, dtype=torch.float32, device=device) / self.dim))
# Strip any legacy "*.inv_freq" keys from old checkpoints before load_state_dict!
Tracked by .to(device) · Excluded from state_dict() · Immune to stale overwrites

7 / 7 · MY TAKE

Architect Verdict: Reserve persistent=True Strictly for Learned Running Stats (BatchNorm)

✅ Good fit
• `persistent=False` for all deterministic buffers (`RoPE inv_freq`, `cos/sin` caches, causal masks, `ALiBi` slopes)
• Top-level shared `RotaryEmbedding` across all Transformer layers
• `persistent=True` only for data-dependent running stats (`BatchNorm running_mean`)
⛔ Not for
• Calling `register_buffer` without `persistent=False` on `inv_freq` or causal masks
• Storing tensors as plain Python attributes (`self.t = ...`) on `nn.Module`
