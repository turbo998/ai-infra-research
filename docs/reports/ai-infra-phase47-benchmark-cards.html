7 / 7 · MY TAKE GOOD FIT VS NOT FOR & PRODUCTION READINESS

Production Guidance: Adopt Fused NVFP4+FP8 DiT & C-Level Protobuf Extend Now; Gate XPU dma-buf on Unpooled USM

✅ GOOD FIT (RECOMMENDED)

  • Blackwell (`sm_100a`/`sm_103a`) Diffusion Serving: Enabling static NVFP4 linear + CUTEDSL per-tensor FP8 MHA cuts FLUX.1-dev latency by 41–43% with zero LPIPS loss.
  • TP2 / TP4 Low-Latency AllReduce + RMSNorm: In-flight peer scale overlap and pass-2 shared-memory value reuse deliver free 1.01–1.038x gains across B200/GB300/GR100.
  • Disaggregated Attention-TP Decode (SGLang) & Multi-Process KV Cache (LMCache): Collective ReduceOp.MAX KV release prevents TP pool divergence, while C-level extend() doubles 32K lookup throughput.
  • GDN Hybrid Models in Megatron-LM: Single-update GDP (`num_householder=1`) with in-place padded chunk descriptors unlocks full prefill+decode CUDA Graphs.

⛔ NOT FOR (AVOID / GATE CAREFULLY)

  • Default Pooled Level Zero USM on Intel XPU RDMA: Passing pooled USM sub-allocations to ibv_reg_dmabuf_mr aliases slab offset 0; always require EnableDeviceUsmAllocationPool=0.
  • Native TRT-LLM MMHA on Gemma4 Global Layers: Non-SM100f GPUs cannot run native MMHA at head_dim=512, GQA=16; route to FLASHINFER FA2 with KVCacheManagerV2.
  • Using sm_100f Family Fallback for CUTLASS Kernels on GR100 (`SM107`): Fails driver Mercury Validator unless compiled with native sm_107a guards.
  • Holding Python GIL Across Rust Tokio block_on: Deadlocks whenever background tasks invoke Python callbacks; always wrap in py.allow_threads.
