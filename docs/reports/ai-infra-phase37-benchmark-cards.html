7 / 7 · MY TAKE · GOOD FIT VS NOT FOR & PRODUCTION READINESS ARCHITECTURAL GUIDANCE · PHASE 37

Adopt Relaxed Forced-Tile Re-Pins, Default Elementwise Regions & Lock-Free Read Leases—With Clear Boundaries

Bilingual synthesis for Cloud & AI Infrastructure Solution Architects deploying Blackwell SM12x/GB300, ROCm CDNA4, and disaggregated KV stores.

✅ Good Fit (推荐使用场景)

  • Blackwell SM12x (GB10) Weight-Only NVFP4 MoE Serving: Upgrade FlashInfer to include `#6292` (`fc8cfd0043`) so `B12xMoEWrapper(quant_mode="w4a16")` serves `Qwen3.6-35B-A3B-NVFP4` with TC-decode ultra FC2 (`tile_k=32, tile_n=512`), gaining `+2.58` GSM8K points over W4A4.
  • ROCm CDNA4 (`gfx950`) Kimi-K3 MLA Serving: Enable `KimiK3MergedQKVGateLinear` (`5,184` cols) and `fused_mla_prefill_qkv_fp8` with zero-copy `q.as_strided` head padding.
  • TorchTitan Muse Spark Base / Debug / RL DAPO Recipes: Inherit the 6 default `local_compile_regions` (`-13.6%` to `-16.6%` train, `-14.6%` prefill/decode vs `main` on GB300) and drop `helion==1.1.0`.
  • High-Read-Concurrency KV Stores & RBLN NPUs: Use Mooncake `LeaseEvictionIndex` (`observes_reads=false`) and LMCache `NL_X_NB_TWO_NH_ONE_BS_HS = 19` (`-50%` `memcpy_v2v` pairs).

⛔ Not For (不适用或需规避场景)

  • Bitwise-Deterministic Muse Spark Runs: `muse_spark_input_scaled_rmsnorm` is not batch-invariant and reorders FP sums/FMAs; batch-invariant evaluation recipes must explicitly clear `local_compile_regions`.
  • Muse Spark Unified KV Pools with `_fused_kv_store`: Never force contiguous-layer `_fused_kv_store` when `--enable-unified-memory` interleaves layers per token row; let it return `None` (`cfec1b91bb`).
  • DFLASH + FA4 Drafts on Quantized Host KV Caches: Do not fuse draft KV into host KV when host uses `fp8`/`fp4` and DFLASH FA4 uses `bf16` compute dtype.
  • Dynamo `RouterMode::KV` with `--use-vllm-tokenizer`: Text-input workers lack frontend token IDs and are now rejected at discovery (`1b6fee46c8`); enable frontend tokenization or use `RoundRobin`.
