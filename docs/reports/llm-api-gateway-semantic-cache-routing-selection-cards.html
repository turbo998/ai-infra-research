Perturbation & Consistency Analysis

1. 为什么扩容反而变慢？ 在未配置 KV-Prefix 路由的集群上，把副本数从 2 扩到 32 会让每个节点沦为孤岛（命中率 `32.5% -> 2.0%`），多出来的 62% Prefill 重算量直接吃掉了新增机器的算力！

2. 热点前缀防单点打爆（Bounded-Load Consistent Hashing）：当某份热门公司公告被上千人同时提问时，KV 路由器在单节点队列超过阈值时自动将流量溢出至第 2 个备用亲和节点，兼顾高命中与负载均衡。

Robustness Conclusion: Never scale out vLLM/SGLang replicas behind a stateless proxy; `KV-Prefix Affinity Routing` is mandatory whenever `Replicas >= 2`.
