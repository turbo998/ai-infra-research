`PPO (36Ψ)` vs. `GRPO (18Ψ)` Memory & Advantage Math

M_PPO = 16*Psi (Actor) + 16*Psi (Critic) + 2*Psi (Ref) + 2*Psi (RM) = 36*Psi
M_GRPO = 16*Psi (Actor) + 2*Psi (Ref) = 18*Psi!
