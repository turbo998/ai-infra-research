4 / 7 · UNDER THE HOOD

`cuCheckpointProcess` Four-State Machine

RUNNING -> cuCheckpointProcessLock() (Drain active CUDA streams)
LOCKED -> cuCheckpointProcessCheckpoint() (Migrate GPU VA/HBM)
CHECKPOINTED -> CRIU dumps Linux process tree (0 GPU HBM used!)
RESTORE -> CRIU + cuCheckpointProcessRestore() -> Unlock (3.2s!)

Because virtual GPU memory addresses are preserved across checkpoint/restore, pre-captured `CUDA Graphs` remain 100% valid without re-recording!

Supported natively in NVIDIA Driver R550+ (`cuda-checkpoint` utility)
