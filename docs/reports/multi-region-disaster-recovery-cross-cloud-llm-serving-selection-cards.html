def route_global_llm_request(req, regions, cloud_burst_pool):
    home_reg = consistent_hash_ring.get_node(req.conversation_id)
    # 1. 若主地域健康且未超载，或该请求已是第 2+ 轮老会话（家里有现成 32K KV 缓存），优先钉在主地域！
    if home_reg.is_healthy and (home_reg.load < 0.85 or req.turn_index > 1):
        if home_reg.load < 0.98:
            async_replicate_token_ids_64kb(req.conversation_id, req.token_ids, peer=home_reg.backup)
            return home_reg

    # 2. 若主地域过载 (>85%) 且是第 1 轮新会话 (Turn == 1)，脱敏溢出至次选地域或公有云 TEE 池
    if req.turn_index == 1 and not req.has_restricted_pii:
        return cloud_burst_pool if home_reg.backup.load > 0.85 else home_reg.backup

    # 3. 主地域故障宕机：唤醒备份地域读取已同步的 64KB 历史 Token 流，0.45s 按需重建 KV 并无缝续写！
    cached_tokens = home_reg.backup.load_replicated_transcript(req.conversation_id)
    return home_reg.backup.lazy_reconstruct_kv_and_resume(cached_tokens + req.new_tokens)

7 / 7 · MY TAKE · GOOD FIT VS NOT FOR & PRODUCTION READINESS Architect Decision Guide

架构师总结：同城跨 AZ 传压缩 KV，异地跨城传 64KB 文本流 + 混合云削峰

把有状态 KV 亲和性放进全球流量调度的第一性原理，告别无状态轮询的算力灾难。

✅ Good Fit (强烈推荐场景)

  • • 金融/政企异地两地三中心与全球 SaaS → Tier 4 (有界哈希粘性双活 + 64KB 文本流重放 + 混合云溢出)：1.8s RTO，91.2% 缓存命中，年省 $265.6 万。

⛔ Not For (严禁踩坑场景)

  • • 严禁对多轮大模型开启跨地域无状态 Round-Robin 轮询 (Tier 2)：直接砍半 KV 缓存命中率，首字延迟暴涨 6.62 倍。

  • • 严禁把涉密 PII 流量直接明文溢出至非机密公有云实例：必须先分级脱敏或使用硬件加密 CC-On TEE 实例。
