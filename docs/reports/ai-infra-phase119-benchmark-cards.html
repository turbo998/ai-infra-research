2 / 7SCENARIO: SM103A/SM107A KERNEL & MEMORY INVARIANTS

Eliminating 8B Stack Spill on SM103a MXFP8 & 28.25 GB Waste in TE Permutation

Input Contract: High-volume MoE activation/routing shapes across SM100/SM103/SM107 and JAX/PyTorch training pipelines

Case 2A · FlashInfer cake_gated_act_mxfp8 (#7568) & cake_kda (#7576) Act automatically

On sm_103a backward rowwise at M * K >= 2^26 (67,108,864), replacing the 12-CTA/SM build (8 B stack spill) with packed f32x2 sigmoid at 10 CTAs/SM eliminates stack spill (0 B) and reaches up to 1.74x speedup. On sm_107a (R200), glm_intra_v18 uses immediate named-barrier slots for 2 CTAs/SM, cutting P14 backward 33.5401 -> 32.0011 ms (1.0481x).

Case 2B · Megatron-LM PinnedActivationBuffer (#7961) Act automatically

Variable-shape MoE offloads ([130, 190, 260, 310, 400] MiB) previously triggered power-of-two PyTorch pinned cache growth (2048 MiB). Packing into one 256B-aligned cudaHostAlloc buffer requires 1290 MiB (37.01% pinned RAM reduction) while isolating CUDA Graph ranges [0, graph_end).

Case 2C · TransformerEngine Permutation Reference (#3609) & LMCache MP (#5911) Confirm

Scattering 1D token indices before row gather cuts reference memory from 30.0 GB to 1.75 GB (17.14x). In LMCache MP, tracking num_engine_computed_tokens = 112 + 188 = 300 stores full chunks (64, 256) instead of truncating at (64, 192).

Verification: All 3 cases validated deterministically via tests/test_phase119_experiments.py with zero fabricated coordinates.

7 / 7MY TAKE · GOOD FIT VS NOT FOR & READINESS

Production Adoption Guide for Phase 119 Kernel, Runtime & Training Upgrades

✅ Good fit (立即采纳场景)

  • Blackwell / Rubin (`SM100a`/`SM103a`/`SM107a`) Serving & Training: Enable 8-range MXFP8 gated activation, `glm_intra_v18` KDA backward, and `CU_TENSOR_MAP_L2_PROMOTION_L2_256B` for narrow-row GEMMs.
  • Fine-Grained MoE Activation Offloading: Set --fine-grained-offloading-buffer-size-gib (multiple of $2^{-22}\text{ GiB}$, i.e., 256B) to eliminate power-of-two host pinned cache growth.
  • PD Disaggregation & Hybrid/DCP KV Caching: Refresh bootstrap_queue[:512] in SGLang and bound LMCache MP stores with num_engine_computed_tokens.

⛔ Not for (不适用或需注意限制)

  • Dynamic-Growth Pinned Offload Buffers: PinnedActivationBuffer allocates once and never grows; under-sizing below peak in-flight microbatch offload bytes raises a hard capacity error.
  • Non-Linear Expert Placement with LoRA + EP: round_robin placement is explicitly rejected in FusedMoEWithLoRA until index mapping supports non-linear EP shards.
  • Outer TileLang JIT Cache Invalidation: Bisheng version is added to the inner .aibin device cache; restart processes after changing toolchains.
