# Hierarchical Pairwise Tree (Good):
# Level 1 (Intra-Node NVLS): sum 8 ranks in FP32 hardware -> node_sum_8
# Levels 2..6 (Inter-Node Binary Tree): always add two equal-magnitude sums (node_A + node_B)!
