✅ Good Fit (Deploy Now)

  • Long-Context CP KDA Training (`CP=8..16`): Enable 2-CTA 64-column state walks (`flashinfer#7436`) to double SM residency (`2 CTAs/SM`) on GB300/B200 when per-rank segment chains are sparse.
  • Blackwell Decode & Sparse MoE Quantize: Use early TMEM free + pre-loop scale conversion (`#7419`, up to `1.205x`) and integer UE8M0 grouped MXFP8 quantize (`#7431`, up to `1.3632x`).
  • High-Fanout Agent / RL Rollout Routing: Enable `--cache-pending-prefix-consult-below` and `--cache-pending-prefix-max-followers` (`sglang#46505`) plus `/get_hicache_l3_cache_layout` (`#40467`).
  • Multi-Stream GPU-Direct RDMA KV Transfer: Upgrade NIXL GPUNetIO (`nixl#2222`) so control/notification streams get independent QPs (`5.58x–7.36x` P50 speedup).

⛔ Not For / Watch Out

  • Unbounded Pending-Prefix Followers on Cold Bursts: Never leave `max_followers` uncapped when parallel sampling sends 32–64 identical cold prefixes simultaneously.
  • Runtime Bool Flags for CuTe-DSL TMEM Bypass: Never pass plain Python `bool` where `cutlass.Constexpr[bool]` is required (`fa4#2906`), or empty block-sparse tiles will read garbage TMEM.
  • Sub-128KiB Staging Pools on Blackwell Sparse FMHA: Always enforce `_TMA_MIN_BACKING_BYTES = 128 KiB` (`trtllm#18843`) for unbounded TMA row domains.
  • Unchecked `Distributed` Weight Wrappers in MoE: Ensure `GroupedLinear` binds FP32 `main_grad` (`te#3397`) rather than silently falling back to BF16 accumulation.
