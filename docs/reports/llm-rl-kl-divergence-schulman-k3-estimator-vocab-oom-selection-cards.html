4 / 7 · UNDER THE HOOD

Derivation & Implementation of Clamped Schulman `k3`

// 1. Only 1D sampled-token logprobs [B, S] are needed (0.12 MB): // log_r = log pi_ref(y_t | x) - log pi_theta(y_t | x) log_r = logprobs_ref - logprobs_theta
↓ Overflow-Safe Non-Negative `k3` Estimator (<answer>)
// 2. Clamp log_r BEFORE exp() to prevent rare-token Inf explosions, // while keeping exact unbiased control variate E_pi[r - 1] = 0: log_r_clamped = torch.clamp(log_r, min=-10.0, max=10.0) k3_kl = torch.exp(log_r_clamped) - 1.0 - log_r_clamped // Strictly >= 0.0! loss = pg_loss + beta * k3_kl.mean()
Near `log_r = 0`, Taylor expansion gives `k3 ≈ 0.5 * log_r^2` with zero bias.
