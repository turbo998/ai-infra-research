UNDER THE HOOD

Blank and nonblank ends cannot be merged before repeated-label updates.

SYNTHETIC INPUTS · independently_reproduced=false · CPU timing separately measured; no ASR-quality claim

prefix state: (log_pb, log_pnb)
pb = paths ending in blank
pnb = paths ending in a nonblank label

blank step: new_pb(prefix) += total(prefix) * P(blank)
same label, no emission: new_pnb(prefix) += pnb * P(label)

↓ a repeated emitted label requires a separating blank

repeat extension:
    new_pnb(prefix + label) += pb * P(label)
different-label extension:
    new_pnb(prefix + label) += (pb+pnb) * P(label)

Actual implementation uses logadd, not linear multiplication.
LM, hotword, BPE and timestamp states are excluded.
Source scope: inspected pyctcdecode merges log scores and retains last-character/partial state; its streaming API also carries LM caches, processed frames and finalization flags.
