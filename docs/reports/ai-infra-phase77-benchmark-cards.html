Adopt 5D Ragged TMA, Per-Peer EP Mailboxes, & Token-Granular HiSparse Immediately in Production Stacks

✅ Good Fit (When to Adopt)

Blackwell / Rubin MoE Training & Decode: Use cake_gated_act_mxfp8_backend (#7305) and per-shape cake_router_gemm (#7287) across B200, GB200, GB300, and R200.
Single-Node EP8 Low-Latency Decode: Enable fused staging copy + 1-warp arrive-only peer mailboxes + inline dispatch routing for M ≤ 16 (#7300).
Preallocated / Varlen KV Cache Kernels: Use FA4's 5D load-safe ragged TMA descriptor (#2983/#3012/#3013) to hardware-zero OOB rows past seqlen_k.
DSV4 HiSparse & Megatron CP Distillation: Mandatory upgrade to SGLang #45104/#46138/#46154, vLLM #60513/#60810, and veRL #8325/#8332 to eliminate silent corruption.

⛔ Not For (Boundaries & Anti-Patterns)

Inline EP8 Routing at M > 16: Do not inline routing into dispatch above 16 tokens/rank; standalone route kernel avoids register spill (#7300).
Store-Only ptr_shift=True on TMA Loads: Never shift TMA base pointer outside mapped memory for loads; use 5D 64-bit unsigned wraparound instead (#2983).
Modulo Page-Size Heuristics on Scattered Decode: Never infer contiguous page backup from numel() % page_size == 0 in decode batches (#45104).
Arch-Less Container Builds: Do not compile TileLang CUDA kernels on CPU build hosts without pinning arch or TILELANG_DEFAULT_TARGET (#2860).
