TP×128 Vocab Padding, Ghost Masking & PP Endpoint Sync

// 1. Pad vocab so every TP rank gets a multiple of 128 rows: divisor = tp_size * 128 # 8 * 128 = 1024 V_pad = ((V_raw + divisor - 1) // divisor) * divisor # 152,064
↓ Ghost-Row `-inf` Mask & PP Tied Grad All-Reduce (<answer>)
// 2. On last TP rank, mask ghost rows [V_raw : V_pad] before softmax/sample: if tp_rank == tp_size - 1: local_logits[:, (V_raw - vocab_start_idx):] = -float("inf") // 3. When tie_word_embeddings=True across PP, sync Stage 0 & Stage P-1: if is_pipeline_first_stage() or is_pipeline_last_stage(): dist.all_reduce(word_embeddings_weight.main_grad, group=embedding_pg)
Prevents ghost token IDs `>= len(tokenizer)` from ever being sampled.

7 / 7 · MY TAKE

Good Fit vs Not For & Production Readiness

✅ Good fit
• All LLM pretraining, SFT, and serving engines (`Megatron-Core`, `vLLM`, `SGLang`)
• Models where `config.vocab_size > len(tokenizer)` (e.g., Qwen2.5 `152,064 vs 151,665`)
• Pipeline-parallel training of tied-embedding models (`Llama-3.2-1B/3B`, `Qwen2.5-3B`)
⛔ Not for
• Using raw `len(tokenizer)` directly as `nn.Embedding` / `lm_head` dimension
• Leaving `[len(tokenizer) : config.vocab_size]` unmasked during high-temperature sampling
