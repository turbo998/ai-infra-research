7 / 7 MY TAKE · ARCHITECT DECISION GUIDANCE & PRODUCTION READINESS

Good Fit vs. Not For: Use Set-of-Marks for Visual Grounding and CDP API Bypass for Speed

Actionable architecture rules for enterprise Browser and Computer-Use Agent platforms.

✅ Good Fit (When to Adopt Tier 4 / Tier 3)

  • Recurring Enterprise SaaS & ERP Automation (Tier 4): Warm session pool + CDP in-page `fetch()` API bypass delivers 91.8% success in 4.2s.
  • Open-Web Exploration Across Unfamiliar Sites (Tier 3): Pruned CDP Accessibility Tree + Set-of-Marks `[#ID]` overlay achieves 96.8% single-click accuracy.
  • Pixel-Only Citrix / Legacy Desktop Apps: Pair screenshots with an `OmniParser` UI bounding-box detector to generate `[#ID]` marks before VLM selection.

⛔ Not For (When to Avoid)

  • Dumping Unfiltered `page.content()` HTML Into LLMs (Tier 1): Wastes $2,460/1k tasks on CSS noise and fails on hidden/Shadow DOM elements.
  • Raw `(x, y)` Pixel Coordinate Guessing on Dense Tables (Tier 2): Suffers 18.4% off-by-15px mis-clicks.
  • Fixed `sleep(5)` Timers Between Clicks: Always wait on deterministic `DOM Mutation + Network Idle` signals.

Day-1 Production Browser Agent Checklist

1. Extract visibility-filtered CDP AXTree and render Set-of-Marks [#1..#N] bounding boxes on screenshots.
2. Maintain a Pre-Authenticated Browser Context Pool (storageState) to skip cold SSO/MFA logins.
3. Promote multi-page table queries and form submissions to in-page fetch() API calls via CDP Network sniffing.
4. Enforce a Pre-Commit Visual Confirmation Gate before destructive write actions.
