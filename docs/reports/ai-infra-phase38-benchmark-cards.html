7 / 7 · MY TAKE · GOOD FIT VS NOT FOR & PRODUCTION READINESS ARCHITECT DECISION GUIDE

Architectural Adoption Guide: Where Phase 38 Optimizations Deliver Immediate Value

EN: Practical guidance for cloud solution architects deploying Blackwell/Rubin kernels, hybrid KV caches, and elastic MoE serving.
中文：面向云解决方案架构师的 Blackwell/Rubin 算子部署、混合 KV 缓存与弹性 MoE 服务落地指南。

✅ Good fit / 适用场景

  • Sub-binned Rubin / Blackwell Cloud SKUs (缩减版 SM 云实例): Capping persistent look-back `vcount` at `min(table_v, sm_count)` immediately recovers 35%–64% lost throughput on 208-SM R200 parts without recompiling device kernels.
  • Low-Batch Context-Parallel Speculative Decode (低批次 CP 投机解码): `cake_fmha` Program 2 (`static_one_wave`) removes device-planner barrier overhead when total chunk+reduce tickets fit in a single SM wave (`1.159x` on B200).
  • Hybrid Full + SWA + Mamba Prefix Caching (混合模型前缀缓存): Separating `reclaimable_value_len` from logical `value_len` and draining sub-pool free pages from each pool's own end prevents ledger drift and interior fragmentation.
  • Unquantized BF16 MoE Exports & Elastic-EP over NIXL (BF16 检查点导出与弹性 EP): Filtering FP8/MTP keys in TorchTitan and setting explicit BF16 + `deep_gemm` + 1024-token NIXL dispatch budgets in Dynamo SGLang.

⛔ Not for / 不适用边界

  • Full-Die 212/216-SM R200, 148-SM B200, or 152-SM GB300 Boards: `_chunk_parallel_vcount` is a no-op (`min(table_v, sm_count) == table_v`); expect 1.000x bitwise-identical execution on non-sub-binned boards.
  • High-Batch Multi-Wave Speculative Decode (`B*Hkv*(n_max+8) > SM`): Shapes like `prod_b8_s8192_q4_cp4_graph` or `cp1_peer_b1_s8192_q4` (132 pages → 328 tickets) require the dynamic device planner (Program 1) or `at_or_above_grid` (Program 0).
  • Quantized Serving on vLLM ROCm Without Validation: `+rms_norm_gated` is enabled by default only when `model_config.quantization is None`; quantized serving paths remain opt-in.
  • Stale NIXL V1 Trace Plugins: NIXL `56c1c2f706` bumps the plugin ABI to `V2` (`pushContext`); out-of-tree `V1` plugins are rejected by `traceLoader` until recompiled.
