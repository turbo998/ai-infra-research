7 / 7 · MY TAKE

Good Fit vs Not For & Production Readiness

✅ Good fit
• Multi-tool MCP / Function-Calling LLM gateways (`20–100` tools per request)
• High-QPS OpenAI-compatible `/v1/chat/completions` servers
• Assistant-prefill (`continue_final_message=True`) and reasoning models
⛔ Not for
• Running uncompiled Python `Jinja2` inside the main `asyncio` event loop thread
• Calling `tokenizer.encode(chat_str, add_special_tokens=True)` on rendered templates
CSP self-contained · Zero external assets · Ready for main branch archive.
