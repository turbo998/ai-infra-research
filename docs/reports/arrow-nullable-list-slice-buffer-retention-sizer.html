ROUND 108 · IMMUTABLE BUFFERS · SYNTHETIC OWNERSHIP BUDGET

Zero-copy still retains its parent.
零拷贝不等于零驻留，null 不等于空列表。

Parent row offset 同时影响 offsets 和 validity bits；child offsets 已是子数组坐标，不要再加一次 parent offset。Raw child span 可以包含 null parent 背后的隐藏数据，不等于 logical flatten。

边界：Backing/visible counts 为 synthetic 输入，位图 flag 仅表示 buffer 是否存在。原始复制策略会丢弃 null parent 的隐藏 child spans，不是 pyarrow 默认 compact API。

32-bit offset 不够时需另选表示；模型本体仅 List<int32>，工作台字节数不认证其他类型。未测 native Arrow、RSS、实际 allocator 或 peak HBM；其他 alias 仍可保留原 buffer。
