7 / 7 · MY TAKEARCHITECTURAL FIT & READINESS

When to Adopt Phase 99 Optimizations vs Where Guardrails Are Mandatory

✅ Good fit
  • Grace-Blackwell GB200/GB300 QSA NVFP4 Decode: Always use the split `decode_tcgen05` + `merge` path across both `aarch64` and `x86_64`.
  • SP-Sharded DeepGEMM MegaMoE (`vLLM #63541`): Size symmetric buffers to `max_num_batched_tokens // sp_size` to reclaim `87.5%` buffer memory at `SP=8`.
  • Graph-Captured Varlen Context Parallelism (`TorchTitan #5071`): Pair fixed query chunks with `HeadTailCPLoadBalancer` to avoid per-step graph recapture.
  • High-Churn UCX KV Disaggregation (`NIXL #2365/#2423`): Force-close UCP endpoints on disconnect while masking `ERR_HANDLER` only when a callback exists.
⛔ Not for
  • Batch-Max-Only cuDNN Full-Prefill Routing: Never admit a paged batch to cuDNN full prefill based solely on `max_q == max_kv` when any request has `Q_i < KV_i`.
  • PTRR Load Balancing Under Graph-Captured Varlen CP: Pin-the-Tail Round-Robin creates excessive chunk fragmentation incompatible with fixed-chunk CUDA Graph replay.
  • Silent Host `memcpy` Fallbacks in RDMA/Device Plugins: Never mask failed `cuCtxSetCurrent` calls in transfer engines (`Mooncake #4839`).
