7 / 7MY TAKE · GOOD FIT VS NOT FOR & PRODUCTION READINESS
Architect Verdict: Use DiskANN on NVMe for Cost-Optimal RAG; Add GPU CAGRA + RaBitQ for High QPS

✅ Good Fit (When to Use Tier 3 / Tier 4)

  • 50M–10B+ Enterprise RAG & ColQwen2 Visual Patch Search (Tier 3/4): Cuts DRAM by `23x–27x` while holding `95%–96.8%` recall.
  • Streaming Ingestion Without Downtime (Tier 4): Training-free RaBitQ never suffers K-Means codebook drift.
  • Daily Large Index Rebuilds (Tier 4): GPU cuVS CAGRA cuts 1B build time from `18.5h` to `1.2h`.

⛔ Not For (When to Avoid)

  • Never run DiskANN over network EBS / NAS: DiskANN requires local PCIe NVMe (`i4i` / `Lsv3`) with `io_uring` for `<0.5ms` 4KB random reads.
  • Never deploy unreranked PQ on technical/financial RAG: Always oversample 3x–4x and rerank with exact vectors.
