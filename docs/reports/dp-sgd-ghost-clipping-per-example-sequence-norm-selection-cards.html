UNDER THE HOOD

Sequence ghost norms need every token-pair inner product.

SYNTHETIC · independently_reproduced=false · no DP guarantee, secure RNG or GPU measurement

G_i = SUM_t outer(delta_it, activation_it)
||G_i||² = SUM_t,u dot(delta_it, delta_iu)
                      * dot(activation_it, activation_iu)
bias_i = SUM_t delta_it
global_norm_i = sqrt(||G_i||² + ||bias_i||²)

↓ stop coefficients before the weighted second backward

c_i = min(1, C / (global_norm_i + 1e-6))
clipped_sum = SUM_i stop_gradient(c_i) * gradient_i
noisy_sum = clipped_sum + sigma*C*z
release = noisy_sum / expected_batch_size

z here is a fixed synthetic vector, NOT Gaussian RNG.
No accountant or privacy guarantee is provided.
Source boundary: Opacus also accounts for accumulated_iterations in mean scaling. The toy fixes one logical release and an explicit expected denominator.
