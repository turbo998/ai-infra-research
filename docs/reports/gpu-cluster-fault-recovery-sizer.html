① 📌 核心结论速览（Executive Summary）

1. 单机 / 中小规模同机混部（≤8 卡）

通用多模型 SaaS 与多模态批量编码首选 vLLM v0.19.1（批量编码器 CUDA Graph 提速 3.20×，长输出开启 --async-scheduling 吞吐 +11.9%）；多轮 Agent、共享长 System Prompt 与 JSON 结构化输出首选 SGLang v0.5.10（RadixAttention 在 16K 上下文 75% 命中率下 TTFT 从 186.4 ms 降至 54.0 ms，提速 3.45×，QPS 达 2.85×）；Blackwell/Hopper 固定主干模型压榨极限单请求 TPOT 选 TensorRT-LLM v1.3.0（8.6 ms，1.35×）。

2. 中大规模长上下文与 PD 分离（≥32 卡 + 400G RDMA）

当输入 ≥8K tokens 或并发较高时，同机混部会发生 Prefill-Decode 干扰（P99 TPOT 飙升至 68.4 ms）。采用 Dynamo + Mooncake 实施 PD 分离（32K 上下文 1.024 GB = 8.192 Gb KV 载荷经 400G RoCEv2 按 44.91 GB/s = 359.30 Gbps 实效带宽零拷贝传输仅需 22.8 ms），将 Decode P99 TPOT 压至 18.2 ms（3.76×），单卡 SLA 吞吐提升至 1,618.4 tok/s/GPU（2.38×），异构 4P+4D 配比将单百万 Token 成本从 $0.76 降至 $0.50（-34.2%）。

3. 超大 MoE 量化与专家并行（671B/37B · 64 卡集群）

稠密中小模型低并发选 W4A16 (AWQ/Marlin)；高并发或超大 MoE 在 Hopper/MI300X 上选细粒度 FP8 (1×128 / 128×128)，在 Blackwell B200 上选硬件原生 NVFP4。跨机部署 671B MoE 严禁无脑跨机纯 TP=16，应采用 Attention DP + MoE EP + DeepEP + EPLB：64 卡 FP8+DP8/EP8 达 92,200 tok/s（较 BF16 TP=16 提升 2.65×，P99 TPOT 15.8 ms，$0.35/1M，-62.0%），Blackwell NVFP4+DP16/EP16 达 151,200 tok/s（4.34×，$0.21/1M，-77.2%），EPLB 消除 Zipf 热门专家倾斜（P99 TPOT 从 25.1 ms 降至 15.8 ms，-37.1%）。
