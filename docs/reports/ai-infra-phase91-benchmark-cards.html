7 / 7MY TAKE

Architectural Guidance: When to Adopt Phase 91 Mechanisms

✅ Good Fit (Adopt Immediately)
  • Blackwell PDL Quant+GEMM Chains: Stream initial weight + scale tiles into L2 before `cudaGridDependencySynchronize()` on small-M decode shapes.
  • NVLink Ulysses Sequence Parallelism: Pre-register output tensors via collective CUDA IPC (`allocate_output`) to eliminate staging copies.
  • Host-DRAM P2P KV Tiering over NIXL/UCX: Enforce `engine_config="TLS=^rc_gda"` and mark sessions dead on `ConnectAck` send errors.
  • Disaggregated Serving & CP Distillation: Order GEN admission by orchestrator arrival (`orig_elapsed_s`) and align teacher top-k `cp_layout` with student THD packing.
⛔ Not For (Avoid Misapplication)
  • Un-fenced `cp.async` → `tcgen05.cp` / TMA Reuse: Never rely on `__syncthreads()` alone between generic shared-memory writes and async proxy reads/writes.
  • ROCm/CK Split-KV with `num_splits > 8`: Do not exceed 8 splits on `gfx950` CK combine without verifying FP32 reference error (`rel_err` spikes to `0.28..2.0`).
  • Large-M Saturated GEMMs for Entry Prefetch: Skip entry L2 weight prefetch when M-tiles already saturate SMs and L2 capacity.
  • Middle-PP Dataset Construction with Sequence Packing: Let rank 0 / last stage broadcast packing metadata instead of building duplicate middle-stage datasets.
