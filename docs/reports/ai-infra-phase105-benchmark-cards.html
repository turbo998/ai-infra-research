7 / 7MY TAKE · ARCHITECT GUIDANCE & READINESS

When to Deploy Phase 105 Mechanisms vs Where Boundaries Apply

✅ Good Fit

  • SM103 GLM-5.3-Flash Serving (`T >= 33`): Enable `mhc_fused_post_pre` with `mhc_fused_post_pre_warmup` before CUDA graph capture (`2.16x` decode speedup).
  • Disaggregated GLM DSA/MTP Prefill: Enable `--enable-kv-cache-sharding` on prefill workers + CPU HiCache (`8.0x` unique KV capacity).
  • Mixed Interactive + Long-Context Workloads: Enable TRT-LLM V2 `ctx_demote_uncached_tokens` (`6.79x` lower short-request P95 TTFT).
  • CUDA-Graphed MoE EP & Sparse RL Refit: Use TE `NVTE_EP_FUSED_PREPARE_DISPATCH=1` (`2.14x`) and Mooncake COO sparse range transfers (`7.76x`).

⛔ Not For

  • `mhc_fused_post_pre` at `T <= 32` or Non-SM103 GPUs: Keep the single-kernel small-batch path for `T <= 32`; SM103 kernels fall back to reference on earlier architectures.
  • KV Sharding on Decode Workers: Decode workers require full KV caches and must not enable `--enable-kv-cache-sharding`.
  • Unaligned Mamba Block Sizes in Batch-Invariant Mode: `enable_prefix_caching` under `batch_invariant_mode` requires `block_size_tokens % ssm_chunk_alignment == 0`.
