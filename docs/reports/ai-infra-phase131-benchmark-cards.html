✅ Good Fit (Recommended Production Adoption)

• DeepSeek-V4.1 NVLink Domain: Keep GPU Engram tables on in-place NVLink reads (`54d2f65`) and guard Custom All-Reduce from integer metadata (`c240169`).
• Megatron Long-Context Training: Use `16x512` streamwise residual backward tiles (`26020f4`) to eliminate FP32 register spills.
• AMD CDNA3/CDNA4 Kernels: Use `cdna{3,4}.buffer.atomic_load/store` (`71114a1`) for device-side flag polling.

⛔ Not For (Anti-Patterns & Hard Boundaries)

• Do NOT run scalar atomics in AMD multi-CTA kernels (`a950b39`): Hardware lacks cross-WG scalar atomic support; use buffer atomics.
• Do NOT pass `int32`/`int64` tensors to float Custom All-Reduce (`c240169`): Causes silent bitwise NaN/mantissa corruption.
• Do NOT launch fixed-grid cooperative reductions on low-SM GPUs (`9768e2e`): Exceeding resident block capacity deadlocks `cudaLaunchCooperativeKernel`.
