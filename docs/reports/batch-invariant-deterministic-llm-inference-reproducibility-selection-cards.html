✅ 为什么固定 `Split-Size=256` 几乎不损失吞吐？
当 Batch Size 很大时，每个请求切 16 块在固定二叉树下由单个或少量 Warp 快速归约；当 Batch Size 很小时，16 个分块正好铺满空闲 SM，因此仅损失 ~7% 吞吐！
✕ 为什么 `torch.use_deterministic_algorithms(True)` 救不了默认引擎？
PyTorch 的确定性标志只保证**“给定相同输入 Shape 时两次调用结果相同”**，但无法阻止 Continuous Batching 动态改变输入张量的第一维 $M$！
Matrix Summary: `torch.use_deterministic_algorithms(True)` only guarantees run-to-run determinism for identical tensor shapes `[M, K]`; Batch-Invariant Kernels guarantee identical results across different batch shapes `[1, K]` vs `[32, K]`.
