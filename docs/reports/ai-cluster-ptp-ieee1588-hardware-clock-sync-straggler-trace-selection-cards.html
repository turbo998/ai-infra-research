底层内幕：为什么交换机不开启 TC/BC，硬件 PTP 也会在 RoCE 洪峰下失准？

# 1. PTP 路径延迟计算假设往返对称: Delay = [(t2 - t1) + (t4 - t3)] / 2 # 但当 400G RoCE 发生 All-to-All 微突发时，PTP 报文在交换机 Egress 队列可能排队 40us， # 而返程排队仅 1us —— 往返严重不对称会导致计算出的时钟偏移产生数十微秒误差! # 解法: 开启交换机透明时钟 (TC) 或边界时钟 (BC)，由交换机 ASIC 硬件精确扣除驻留时间!
