# Multi-Team Enterprise Internal MaaS Platform & FinOps Chargeback Selection (`enterprise_internal_maas_platform_finops_chargeback_selection`)

Deterministic architectural evaluator for **SA Guide**: comparing **Departmental GPU Silos**, **Static K8s Namespace Quotas**, **Shared Base-Model + Dynamic Multi-LoRA Pooling**, and **Full Enterprise MaaS Platform (Token Chargeback + 3-Tier QoS + Night Batch Backfill)**.

## Usage

```bash
python experiments/enterprise_internal_maas_platform_finops_chargeback_selection/run.py
python experiments/enterprise_internal_maas_platform_finops_chargeback_selection/run.py --check
```
