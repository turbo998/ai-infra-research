# GPU Power Capping, DVFS & Rack PDU Oversubscription Selection Experiment (`Workload-Aware Power Cap + Closed-Loop Rack Telemetry` vs. `Uncapped 700W TDP`)

Reproducible datacenter capacity and energy efficiency model comparing 4 GPU power management architectures inside a fixed `10 MW` power-constrained AI datacenter hall.

## Run
```bash
python experiments/gpu_power_capping_dvfs_transient_spike_rack_pdu_oversubscription_selection/run.py
python experiments/gpu_power_capping_dvfs_transient_spike_rack_pdu_oversubscription_selection/run.py --check
```
