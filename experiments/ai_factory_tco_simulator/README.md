# 100K-GPU Full-Stack AI Factory TCO & Token Economics Simulator

Deterministic stdlib evaluation (`experiments/ai_factory_tco_simulator/run.py`) coupling all 6 research phases (`Optics CPO/OCS`, `UEC/SHARP`, `FP8/NVFP4`, `NVRx + 3FS`, `ORv3 Supercap`, and `Hybrid MLA/Mamba Disaggregated Serving`) into a 3-year 100,000-GPU TCO and token cost Pareto model.

## Usage

```powershell
python experiments\ai_factory_tco_simulator\run.py
python experiments\ai_factory_tco_simulator\run.py --check
```
