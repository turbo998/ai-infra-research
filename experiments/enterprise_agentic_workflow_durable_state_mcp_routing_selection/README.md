# Enterprise Multi-Agent Production Serving, MCP Tool Gateway & Planner-Executor Routing (`enterprise_agentic_workflow_durable_state_mcp_routing_selection`)

Deterministic architectural evaluator for **SA Guide**: comparing **Monolithic 180-Tool Prompt Loop**, **Stateless In-Memory Multi-Agent**, **Durable State Graph + Dynamic Top-8 MCP Retrieval**, and **Hierarchical Planner (70B/R1) + Executor (8B SLM) + Append-Only Prefix Cache**.

## Usage

```bash
python experiments/enterprise_agentic_workflow_durable_state_mcp_routing_selection/run.py
python experiments/enterprise_agentic_workflow_durable_state_mcp_routing_selection/run.py --check
```
