# Enterprise Agentic Memory & GraphRAG Selection Experiment (`Microsoft GraphRAG / LightRAG` vs. `Mem0 / Zep` vs. `Full-History Stuffing` vs. `Vector RAG`)

Reproducible accuracy, latency, and TCO model comparing 4 agentic memory and knowledge-graph retrieval architectures across `1.2M` monthly agent turns and a `10,000`-document enterprise corpus.

## Run
```bash
python experiments/enterprise_agentic_memory_graphrag_mem0_zep_hybrid_retrieval_tco_selection/run.py
python experiments/enterprise_agentic_memory_graphrag_mem0_zep_hybrid_retrieval_tco_selection/run.py --check
```
