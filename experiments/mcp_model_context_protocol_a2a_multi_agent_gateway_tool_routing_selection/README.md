Reproducible latency, accuracy, and token TCO model comparing 4 MCP (`Model Context Protocol`) and A2A (`Agent2Agent`) orchestration architectures across `400` registered enterprise tools and `800,000` monthly multi-step agent tasks.

python experiments/mcp_model_context_protocol_a2a_multi_agent_gateway_tool_routing_selection/run.py
