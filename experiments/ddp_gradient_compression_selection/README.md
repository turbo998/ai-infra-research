# DDP gradient communication compression: synthetic break-even model

Round 92, 2026-11-13. **Synthetic, not GPU-measured; independently_reproduced=false.**
This is not a benchmark of model quality or a new PowerSGD implementation for training.

```powershell
python -m experiments.ddp_gradient_compression_selection.run
python -m experiments.ddp_gradient_compression_selection.run --check
python -m unittest tests.test_ddp_gradient_compression_selection
```

`run.py` seals assumptions, derived byte/latency budgets and a three-worker,
4-by-4 rank-one numerical example into `report.json`. `render.py` reads that
same in-memory report to generate the static seven-card deck, standalone H5
calculator and vector summary. `--check` compares every generated byte without
rewriting anything. Tests independently check ring arithmetic, the strict shape
gate, overlap, dense-vector fallback, distributed averaging and the telescoping
error-feedback identity.

For an `m x n` FP32 gradient and factor rank `r`, dense bytes are `4mn`;
factor bytes are `4r(m+n)`. Vectors stay dense. With `W` workers, an ideal ring
sends `2(W-1)/W` times that payload per rank and has `2(W-1)` startup hops per
collective. PowerSGD has two sequential factor collectives plus a modeled
dense-vector collective when vectors are present. All shape groups are treated
as one aggregate bucket; actual multi-bucket scheduling and contention are absent.

`service_ms = communication_ms + codec_ms`;
`step_ms = backward_ms + max(0, service_ms - overlap_ms)`.
The fixed codec budget and shared overlap window are deliberately transparent
simplifications, not GPU measurements or an NCCL algorithm predictor. `GB/s` is
decimal, **not Gb/s**. The baseline uses FP32 gradients: a BF16-trained model
does not necessarily have BF16 gradient buckets, and an already-BF16 bucket
does not gain another 2x from the cast hook.

The toy algorithm uses shared Q, averaged P followed by normalization,
averaged Q, and reconstruction; each worker retains its corrected gradient
minus the common reconstruction, matching the pinned hook's residual definition.
The cumulative difference telescopes to the final mean residual when error
feedback is enabled. Small numerical discrepancies are floating-point effects.
This identity is **not** a convergence guarantee or task-accuracy result.
